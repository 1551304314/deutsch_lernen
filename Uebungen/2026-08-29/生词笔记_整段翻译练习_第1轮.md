## 题目 1 · Mein Alltag und die Akademie（我的日常与学院）

### das Gymnasium（名词）· 文理中学
- **语法要点**：das, Gymnasien（复数）
- **常见搭配**：aufs Gymnasium gehen（上文理中学）；das Abitur am Gymnasium machen（在文理中学考取 Abitur）
- **例句**：Mein Bruder geht aufs Gymnasium. → 我弟弟上文理中学。
- **辨析/易错**：德国中学分 Gymnasium（文理中学，通向大学）、Realschule（实科中学）、Hauptschule（普通中学）。das Abitur 是"高中毕业考试"，不是"高考"（德国没有全国统一高考，Abitur 通过即获大学入学资格）。

### vorbereitet（形容词·PII）· 准备好的
- **语法要点**：源自 vorbereiten → bereitete vor → hat vorbereitet（可分动词）
- **常见搭配**：gut vorbereitet sein（准备充分）；sich auf + Akk vorbereiten（为……做准备）
- **例句**：Ich habe mich gut auf die Prüfung vorbereitet. → 我为考试做好了准备。
- **辨析/易错**：名词 die Vorbereitung, -en（准备）。"备考"说 sich auf die Prüfung vorbereiten，介词是 auf + 第四格。

### betrachten（动词）· 观看、端详
- **语法要点**：betrachten → betrachtete → hat betrachtet（vt，+Akk，不可分动词）
- **常见搭配**：ein Bild betrachten（看一幅画）；etwas genauer betrachten（更仔细地看）
- **例句**：Er betrachtet die Fotos lange. → 他久久地端详照片。
- **辨析/易错**：近义 anschauen / ansehen 更口语；betrachten 偏书面。注意 betrachten 不可分（ich betrachte，不是 ich trachte … an）。

## 题目 2 · Ein Tag im Amt（市政厅的一天）

### der Antrag（名词）· 申请
- **语法要点**：der, Anträge（复数变音）
- **常见搭配**：einen Antrag stellen（提出申请）；den Antrag abgeben（递交申请）；der Antrag auf ein Visum（签证申请）
- **例句**：Ich habe den Antrag gestern abgegeben. → 我昨天递交了申请。
- **辨析/易错**：申请"某物"用 auf + Akk：ein Antrag auf Urlaub（休假申请）。动词搭配是 stellen/abgeben，不是 machen。

### das Gebäude（名词）· 建筑物、楼
- **语法要点**：das, Gebäude（复数不变）
- **常见搭配**：ein hohes Gebäude（高楼）；das Gebäude betreten（进入大楼）
- **例句**：Vor dem Gebäude steht ein Auto. → 楼前停着一辆车。
- **辨析/易错**：das Haus 泛指"房子"；das Gebäude 更正式，指较大建筑（办公楼、学校等）。

### das Schild（名词）· 牌子、指示牌
- **语法要点**：das, -er
- **常见搭配**：auf dem Schild stehen（牌子上写着）；ein Schild anbringen（挂一块牌子）
- **例句**：Auf dem Schild steht: „Bitte nicht rauchen!" → 牌子上写着："请勿吸烟！"
- **辨析/易错**："牌子上写着"德语的动词是 stehen（站着），不是 schreiben。

### enttäuscht（形容词·PII）· 失望的
- **语法要点**：源自 enttäuschen → enttäuschte → hat enttäuscht
- **常见搭配**：über + Akk enttäuscht sein（对……失望）；von + Dat enttäuscht sein（对某人失望）
- **例句**：Ich bin über das Ergebnis enttäuscht. → 我对结果很失望。
- **辨析/易错**：反义 begeistert（兴奋的）、zufrieden（满意的）。注意介词：对事用 über，对人用 von。

## 题目 3 · Die Planung des Abenteuers（冒险计划）

### erleben（动词）· 经历、体验
- **语法要点**：erleben → erlebte → hat erlebt（vt，+Akk，不可分）
- **常见搭配**：ein Abenteuer erleben（经历一次冒险）；etwas Schönes erleben（经历美好的事）
- **例句**：Wir haben viel erlebt. → 我们经历了很多。
- **辨析/易错**：名词 das Erlebnis, -se（经历、难忘的事件）。前缀 er- 常表"经历并达到目的"（erleben / erkämpfen / erreichen）。

### derselbe / dieselbe / dasselbe（指示代词）· 同一个
- **语法要点**：变格与 dieser 家族相同（derselbe Mann / dieselbe Frau / dasselbe Kind）
- **常见搭配**：derselben Meinung sein（意见一致）；in demselben Haus wohnen（住在同一栋楼）
- **例句**：Wir sind derselben Meinung. → 我们意见一致。Er wohnt in demselben Haus. → 他住在同一栋楼里。
- **辨析/易错**：derselbe = 同一个（完全同一事物）；der gleiche = 相同的（两个同类事物）。口诀：derselbe 只有"一个"，gleiche 有"两个"。

### zustimmen（动词）· 同意
- **语法要点**：zustimmen → stimmte zu → hat zugestimmt（vi + Dativ 三格！可分动词）
- **常见搭配**：jemandem zustimmen（同意某人）；einem Vorschlag zustimmen（同意一个建议）
- **例句**：Alle stimmten ihm zu. → 所有人都同意他。
- **辨析/易错**：接三格宾语！不能接第四格。名词 die Zustimmung, -en（同意、批准）。否定：Ich stimme dir nicht zu.（我不同意你。）

### sicher（形容词）· 安全的；确定的
- **语法要点**：比较级 sicherer → am sichersten
- **常见搭配**：sicher sein（安全的）；sich (D) sicher sein, dass …（确定……）；副词 sicher（肯定、无疑）
- **例句**：Der Weg ist sicher. → 这条路是安全的。Ich bin sicher, dass er kommt. → 我确定他会来。
- **辨析/易错**：作副词时"他肯定来"= Er kommt sicher（不用于保证未来）；注意区分 die Sicherheit（安全）。

### je nachdem（连词）· 视……而定
- **语法要点**：je nachdem, wie / wann / ob / was + 从句（尾语序）
- **常见搭配**：je nachdem, wie das Wetter wird（视天气而定）
- **例句**：Je nachdem, wie das Wetter ist, gehen wir raus. → 视天气而定，我们是否出门。
- **辨析/易错**：属 je 家族（与 je … desto 同源），后接疑问词引导的从句，动词落尾。

## 题目 4 · Die Zugfahrt（火车之旅）

### herumlaufen（动词）· 跑来跑去、到处乱跑
- **语法要点**：herumlaufen → lief herum → ist herumgelaufen（vi，完成时用 sein；可分动词，强变化 e→ie→au）
- **常见搭配**：frei herumlaufen（到处乱跑）；im Garten herumlaufen
- **例句**：Der Hund läuft im Garten herum. → 狗在花园里跑来跑去。
- **辨析/易错**：前缀 herum- = "围着……转、来回"。完成时助动词是 sein（位移动词）。

### kaum（副词）· 几乎不
- **语法要点**：程度副词，常与 etwas / jemand / noch 连用
- **常见搭配**：kaum etwas hören（几乎什么也听不见）；kaum glauben können（几乎不敢相信）
- **例句**：Ich kann es kaum glauben. → 我几乎不敢相信。
- **辨析/易错**：kaum 本身已含否定，句中不再加 nicht。近义 fast nicht。

### abgelenkt（形容词·PII）· 分心的、被分散注意力的
- **语法要点**：源自 ablenken → lenkte ab → hat abgelenkt（可分动词）
- **常见搭配**：abgelenkt sein / werden（分心/被分散注意力）；jemanden ablenken（使某人分心）
- **例句**：Ich wurde ständig abgelenkt. → 我不断被分散注意力。
- **辨析/易错**：名词 die Ablenkung, -en（分心的事物、消遣）。被动 abgelenkt werden 是高频搭配。

### bemerken（动词）· 注意到
- **语法要点**：bemerken → bemerkte → hat bemerkt（vt，+Akk）
- **常见搭配**：einen Fehler bemerken（注意到错误）；ohne dass es jemand bemerkte（没人注意到）
- **例句**：Niemand bemerkte den Fehler. → 没人注意到这个错误。
- **辨析/易错**：bemerken（注意到）≠ merken（记住；察觉）。注意固定结构 ohne dass es jemand bemerkte（异主语）。

### schimpfen（动词）· 骂、发火、抱怨
- **语法要点**：schimpfen → schimpfte → hat geschimpft（vi，规则变化）
- **常见搭配**：mit jemandem schimpfen（责骂某人）；über etwas schimpfen（抱怨某事）
- **例句**：Hier wird nicht geschimpft. → 这里没有人发火。Er schimpft über das schlechte Wetter. → 他抱怨天气不好。
- **辨析/易错**：schimpfen auf/mit + Akk/Dat 表"骂某人"，über + Akk 表"抱怨某事"。文中是被动的无人称结构（Es wird geschimpft）。

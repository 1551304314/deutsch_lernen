## 一、bekommen-Passiv（三格宾语被动 / 受惠者被动）B2

**德语术语**：bekommen-Passiv（Rezipientenpassiv 受惠者被动 / Dativpassiv 三格被动）。

### 1. 为什么需要它
普通被动态只能把 **Akk（第四格）宾语**提为主语。当句子重心是**受益的"人"**（第三格宾语）时，用 `bekommen` 把这个人提为主语。

| 语态 | 例句 |
|---|---|
| 主动 | Die Firma **liefert** mir das Paket. 公司给我送包裹。 |
| 普通被动 | **Mir** wird das Paket geliefert. 包裹被送给我。（人留守第三格） |
| **bekommen-Passiv** | **Ich bekomme** das Paket **geliefert**. 我收到包裹。 |

### 2. 结构：`bekommen（随时态变位）+ PII（句末不变）`

| 时态 | 例句 |
|---|---|
| Präsens | Ich **bekomme** geliefert. |
| Präteritum | Ich **bekam** geliefert. |
| Perfekt | Ich **habe** geliefert **bekommen**. |
| Plusquamperfekt | Ich **hatte** geliefert **bekommen**. |
| 情态动词 | Ich **muss** geliefert **bekommen**. |

### 3. 适用范围（⚠️ 不是万能）
- **动词类型**：只用于带 Dativ 宾语的动词，主要是"给出/传递"类——geben, schenken, bringen, schicken, senden, liefern, zahlen, überreichen, anbieten, versprechen, erzählen, sagen, zeigen, mitteilen。
  - ✅ `Ich bekomme die Wahrheit gesagt.` 我被告知真相。
  - ❌ `*Das Buch bekommt gekauft.` 错误——kaufen 无 Dativ 宾语，只能用 `Das Buch wird gekauft.`
- **语体**：口语/非正式为主。正式书面德语倾向 `Mir wird … + PII`。
- **无 Akk 宾语时**（如 helfen）可说 `Ich bekomme geholfen.`，更口语，书面受限。

**其他助动词**：口语 `kriegen`；非常正式 `erhalten`（少用）。

**记忆技巧**：bekommen 按字面"得到"理解——"我得到被…的动作"，中文译成"我收到…/我被…了"。

## 二、Passiversatzformen（被动替代形式）B2 ⭐ 核心缺口

| 形式 | 结构 | 对应含义 | 语体 |
|---|---|---|---|
| man 结构 | man + 主动 | = wird + PII | 口语/泛指 |
| sein + zu | sein + zu + Inf. | = **muss 或 kann** + PII | 书面/官方 |
| sich lassen | sich + lassen + Inf. | = **nur kann** + PII | 口语/书面 |
| 形容词后缀 | -bar / 少数 -lich | = kann + PII | 书面 |

### 1. man + 主动（A2 已见，正式归入替代体系）
`Man spricht hier Deutsch.` = `Hier wird Deutsch gesprochen.` 这里说德语。

### 2. sein + zu + Infinitiv（"必须"还是"可能"三步判断法）
**构成**：`主语 + ist/sind + zu + Infinitiv`

1. 有程度副词 **gut / leicht / schwer / kaum / nur / ohne weiteres** → 表**可能**（= können）
2. 有**时间/命令/规定**语境（sofort, bis …, Regel, Vorschrift）→ 表**必须**（= müssen）
3. 无提示词的中性句（主语是 Aufgabe/Regel/Plan）→ 通常读作**必须**

| 判定 | 例句 | 等价改写 |
|---|---|---|
| 可能 | Der Text **ist leicht zu verstehen**. | kann leicht verstanden werden |
| 必须 | Die Aufgabe **ist bis morgen zu erledigen**. | muss erledigt werden |
| 不可能（否定） | Das **ist nicht zu ändern**. | kann nicht geändert werden |
| 不可能（否定+程度） | Das **ist kaum zu vermeiden**. | kann kaum vermieden werden |

**限制**：只用于**可被动化的及物动词**；`*Der Hund ist zu bellen` 不成立。

### 3. sich + lassen + Infinitiv（只表"可能"，绝不表"必须"）
- `Das Problem **lässt sich lösen**.` = Das Problem kann gelöst werden.
- `Die Tür **lässt sich nicht öffnen**.` 门打不开。
- `Der Text **lässt sich leicht übersetzen**.`

**与 sein+zu 的本质区别**：sein+zu 兼表必须/可能；**sich lassen 只能表"可能"**，muss 含义永远无法用它表达。

### 4. 形容词后缀（边界讲死）
- **-bar**（动词词干 + -bar）→ "可以被…的"，规则最活：waschbar, essbar, trinkbar, lesbar, lösbar, machbar, sichtbar, reparierbar, übersetzbar
  - ⚠️ **例外**（非被动义，单独背）：dankbar 感恩的、fruchtbar 肥沃的、furchtbar 可怕的
- **-lich** → 被动义是**少数固定词，不可类推**：verständlich, begreiflich, unvermeidlich, erträglich
  - ⚠️ 大量 -lich 与被动无关：freundlich, täglich, körperlich

**等价链条**（同一意思四种说法）：
`Das Problem ist lösbar.` ≈ `Das Problem lässt sich lösen.` ≈ `Das Problem kann gelöst werden.` ≈ `Das Problem ist zu lösen.`

## 三、被动 + 第二虚拟式（修正版表格）B1/B2

**非现实被动只有两层时态**，记住"主动二虚 → 被动二虚"的对应：

| 层面 | 主动二虚 | 过程被动二虚 | 状态被动二虚 |
|---|---|---|---|
| 现在层（非现实现在/将来） | würde + Inf. | **würde + PII + werden** | **würde + PII + sein** |
| 过去层（非现实过去） | hätte/wäre + PII | **wäre + PII + worden** | **wäre + PII + gewesen** |
| 情态动词·现在层 | könnte/müsste + Inf. | könnte/müsste + PII + werden | könnte/müsste + PII + sein |
| 情态动词·过去层 | hätte + Inf. + können | **hätte + PII + werden + können/müssen** | 罕见 |

**例句**：
- 现在层：`Wenn mehr Geld da wäre, würde das Haus schneller gebaut werden.` 若钱更多，房子会建得更快。
- 过去层：`Die Tür wäre längst geöffnet worden.` 门本应早就被打开。
- 过去层状态：`Das Zimmer wäre aufgeräumt gewesen.` 房间本该是收拾好的。
- 情态现在层：`Es müsste mehr für die Umwelt getan werden.` 应更多地为环境做事。
- 情态过去层：`Es hätte früher gemacht werden können.` 这本可以更早完成。

**⚠️ 易混澄清**：`würde + PII + worden sein` 是"二虚将来二时被动"（Futur II 的二虚），**不是**非现实过去，DaF A1–B2 不考，别用。

**记忆**：被动二虚过去层 = 把主动过去层（hätte/wäre + PII）的 PII 换成被动态：worden / gewesen。

## 四、zu-Infinitiv 被动 + Plusquamperfekt/Futur 实操（B1 收尾）

### 1. zu-Infinitiv 被动
结构：`… zu + PII + werden / sein`，常配 scheinen, hoffen, wünschen, bitten 等：
- `Das Haus scheint renoviert zu werden.` 房子似乎正在被翻修。
- `Es ist wichtig, rechtzeitig informiert zu werden.` 及时获知信息很重要。
- `Er hofft, bald eingeladen zu werden.` 他希望能很快被邀请。

### 2. Plusquamperfekt / Futur 被动实操
- **Plusquamperfekt Passiv**（过去之过去，常配 nachdem）：
  - `Nachdem das Problem gelöst worden war, gab es keine Fragen mehr.` 问题解决后，再无疑问。
- **Futur I Passiv**：
  - `Die Aufgabe wird morgen gelöst werden.` 任务明天将被解决。
- **对比 Futur II Passiv**（对应二虚将来二时的直陈式形态）：
  - `Die Aufgabe wird morgen gelöst worden sein.` 明天之时任务将已经完成。

## 五、被动化的限制（哪些动词不能进被动）B1 常考 ⭐

被动不是万能的。三条"禁区"：

### 禁区 1：不及物动词（无 Akk 宾语）
- 只能进**无人称被动**，且限于表"活动/过程"的动词：✅ `Es wurde die ganze Nacht getanzt.` ✅ `Hier wird nicht geraucht.`
- **存在/状态**类不及物动词连无人称被动都不行（sein, bleiben, liegen, stehen, sitzen, existieren）：❌ `*Es wird gelegen.`
- 带 Dativ 的不及物动词 → 无人称被动（`Dem Kind wird geholfen.`）或 bekommen-Passiv。

### 禁区 2：反身动词（详见第七节）
❌ `*Es wird sich gefreut.` 错误。

### 禁区 3：静态/领属/感知类动词——绝对不能被动化
这类动词表"状态"不表"动作"：

| 动词 | 错误句 | 正确表达 |
|---|---|---|
| haben | ❌ `*Der Brief wird von mir gehabt.` | ✅ Ich habe den Brief. |
| wissen / kennen | ❌ `*Es wird gewusst.` | ✅ Das ist bekannt. |
| bekommen | ❌ 不能被动 | ✅ bekommen-Passiv 本身 |
| enthalten | ❌ 不能被动 | ✅ Die Flasche enthält Wasser. |
| kosten | ❌ `*10 Euro werden gekostet.` | ✅ Das Buch kostet 10 Euro. |
| gleichen / ähneln | ❌ 不能被动 | ✅ Sie gleicht ihrer Mutter. |

**判断口诀**：先问"能被…吗？"——拥有、知道、花费、相似这类**状态**动词答不出来，就不能被动；表**动作/过程**的才进得了被动。

## 六、Gerundiv（zu-分词作定语）B1/B2 ⭐

**定义**：`zu + PII` 作名词定语，表"**需要/有待被…的**"（被动 + 必要性）。

**构成**：`zu + PII + 形容词词尾（随名词变格）`

| 例句 | 等价句式 |
|---|---|
| das **zu lösende** Problem 待解决的问题 | = Das Problem ist zu lösen. |
| der **zu reparierende** Motor 待修的发动机 | = Der Motor ist zu reparieren. |
| die **zu erledigende** Aufgabe 待完成的任务 | = Die Aufgabe ist zu erledigen. |

**变格示例**：定冠词 `das zu lösende Problem` / `mit dem zu lösenden Problem`；无冠词 `zu lösende Probleme`（复）。

**三个分词对比**（reparieren）：

| 形式 | 语态·时态 | 例句 |
|---|---|---|
| Partizip I：der reparier**ende** Mann | 主动·进行 | 正在修理的男人 |
| Partizip II：der reparier**te** Motor | 被动·已完 | 已修好的马达 |
| **Gerundiv**：der **zu** reparierende Motor | 被动·需然 | 待修的马达 |

**要点**：
- 只用于**可被动化的及物动词**。
- 否定：`der nicht zu reparierende Motor` = 无法修理的马达（= nicht reparierbar）。
- 可带扩展成分：`die noch zu erledigenden Aufgaben` 尚未完成的任务。
- **记忆**：直译"to be done 的"，对照英语 `the book to be read`。

## 七、lassen 使役结构（lassen + Akk + Infinitiv）B1/B2 ⭐

**含义**：主语"安排/让/允许"某事发生，但**不亲自做**。

**结构**：`lassen（变位）+ 宾语 + Infinitiv（句末）`

| 例句 | 含义 |
|---|---|
| Ich **lasse** das Auto **reparieren**. | 我让人修车。 |
| Ich **lasse mir** die Haare **schneiden**. | 我去理发。 |
| Er **lässt** seinen Sohn die Tür **öffnen**. | 他让儿子开门。 |
| Ich **lasse mich** impfen. | 我让人给我打疫苗。 |

**三个语义**：① 使役（Er lässt das Haus bauen.）② 允许（Die Eltern lassen das Kind fernsehen.）③ 保持/任凭口语（Lass das! / Lass mich in Ruhe!）

**⚠️ 与 sich lassen 一字之差，务必分清**（B1/B2 区分考点）：

| 句子 | 结构 | 语义 |
|---|---|---|
| Das Problem **lässt sich** lösen. | 被动替代 | 问题**可以**解决。 |
| Ich **lasse** das Problem lösen. | 使役 | **我让人**解决问题。 |

**⚠️ Perfekt 双不定式**（句末保留 **lassen** 不定式，绝不写 gelassen）：
- ✅ `Ich habe das Auto reparieren lassen.`
- ✅ `Er hat sich impfen lassen.`
- ✅ 配情态动词：`Er muss das Auto reparieren lassen.`

## 八、反身动词无被动 B1

**铁律**：反身动词的**反身用法**绝对不能被动化。
❌ `*Es wird sich gefreut.` ❌ `*Es wird sich getroffen.`

**关键区分**（考试判断标准）——看动词有无"非反身的及物用法"：

| 动词 | 反身用法（无被动） | 及物用法（可被动） |
|---|---|---|
| waschen | Er wäscht sich. → ❌无被动 | ✅ Das Kind wird gewaschen. |
| treffen | Sie treffen sich. → ❌无被动 | ✅ Das Ziel wird getroffen. |
| anziehen | Ich ziehe mich an. → ❌无被动 | ✅ Die Hose wird angezogen. |

**纯反身动词**（绝对无被动）：sich freuen, sich befinden, sich bedanken, sich erholen, sich beeilen, sich schämen, sich erkälten, sich weigern, sich bemühen...

**被动义的替代表达**：
- 用 man：`Man freut sich über das Geschenk.`
- 用形容词：`Das ist erfreulich.` 这是令人高兴的。
- 用名词：`Die Freude über das Geschenk.`

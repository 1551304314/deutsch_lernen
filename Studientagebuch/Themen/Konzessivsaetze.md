## 一、Konzessivsätze 概念与核心认知

表达**"尽管存在某个事实/障碍，主句的动作仍然发生"**，即"虽然……但是……"。

> ⚠️ **核心规则**：德语主从句之间**不用 aber（但是）连接**，主句直接说结果。中文"虽然……但是……"的"但是"在德语中不存在于让步从句结构里。**obwohl 与 aber 连用是中式错误，禁止！**

| 类型 | 连接手段 | 语序 |
|------|----------|------|
| 从属连词（Nebensatz） | obwohl, obgleich, obschon, wenngleich, obzwar, wenn...auch, auch wenn, selbst wenn | 动词末尾（尾语序） |
| 副词（在主句中） | trotzdem, dennoch, gleichwohl, nichtsdestotrotz, nichtsdestoweniger | 正语序（动词第二位） |
| 搭配连词 | zwar ... aber / doch / jedoch, zwar ... dafür aber | 主句 + 主句 |
| 固定结构 | so + Adj. + auch, wie + Adj. + auch, so sehr ... auch, noch so + Adj., egal + W-Wort, W-Wort + auch (immer), ob...oder, sei es...oder | 视结构而定 |
| 情态动词 | mögen（Er mag noch so reich sein, ...） | 不定式在句末 |
| 介词短语 | trotz, ungeachtet, bei allem/aller, allen...zum Trotz, entgegen | 无动词，名词化结构 |

**三大语义分支**（理解让步的钥匙）：
1. **事实让步**（realer Konzessiv）：障碍是事实 → obwohl / trotzdem / zwar...aber
2. **假设让步**（irrealer/konzessiver Konditional）：障碍是假设 → auch wenn / selbst wenn / wenn auch / wenn schon
3. **无条件让步**（komplexer Konzessiv）：无论何种情况结果不变 → egal/W-Wort + auch immer / so...auch / ob...oder / sei es...oder

## 二、A2：obwohl【常用】— 最基础的让步连词

**规则**：obwohl 引导从句，动词放句末（尾语序）。从句可在主句前或主句后；从句在前时，主句以动词开头。

| 例句 | 翻译 |
|------|------|
| **Obwohl** er krank **ist**, **geht** er zur Arbeit. | 虽然他生病了，他还是去上班。 |
| Ich lerne Deutsch, **obwohl** es schwierig **ist**. | 我学德语，虽然它很难。 |
| **Obwohl** sie kein Geld **hat**, **kauft** sie das Kleid. | 虽然她没有钱，她还是买了那条裙子。 |
| **Obwohl** es stark **regnete**, **ging** er spazieren. | 虽然下着大雨，他还是去散步了。 |
| **Obwohl** er alles **versucht hat**, **konnte** er sie nicht überzeugen. | 尽管他尝试了一切，还是没能说服她。（Perfekt：分词 versucht 在前、助动词 hat 末尾） |

> 📌 记忆口诀：**obwohl → 动词踢到最后！**

> ❌ **高频错误**：Obwohl es regnet, **aber** ich gehe spazieren.（obwohl 和 aber 不能同时用！）
> ✅ 正确：Obwohl es regnet, **gehe** ich spazieren.

**语义**：obwohl 表**事实让步**——从句陈述的是一个真实的、已知的障碍/情况。

## 三、A2：trotzdem【常用】— "尽管如此"（副词，非连词）

**规则**：trotzdem **不是连词**，是副词，不引导从句，而是用在主句中表示"尽管如此"，主句保持**正常语序（动词第二位）**。

| 结构 | 示例 |
|------|------|
| 句子1. Trotzdem + 主句 | *Es regnet. Trotzdem gehe ich spazieren.* |
| 句子1, trotzdem + 主句 | *Es regnet, trotzdem gehe ich spazieren.* |

| 例句 | 翻译 |
|------|------|
| Er ist krank. **Trotzdem** geht er zur Arbeit. | 他生病了。尽管如此，他还是去上班。 |
| Sie hat kein Geld. **Trotzdem** kauft sie das Kleid. | 她没有钱。尽管如此，她还是买了那条裙子。 |
| Das Wetter war schlecht. **Trotzdem** haben wir den Ausflug gemacht. | 天气很糟。尽管如此，我们还是去郊游了。 |

#### obwohl vs. trotzdem 对比

| | obwohl | trotzdem |
|---|---|---|
| 词性 | 从属连词 | 副词 |
| 语序 | 从句尾语序（动词末尾） | 主句正常语序（动词第二位） |
| 位置 | 引导从句（前或后） | 在主句中（不能引导从句） |
| 连接关系 | 从句 ↔ 主句 | 句子 ↔ 句子 |

**转换练习**（两者语义相同，结构不同）：
- *Obwohl es regnet, gehe ich hinaus.* = *Es regnet. Trotzdem gehe ich hinaus.*
- *Obwohl er krank ist, geht er zur Arbeit.* = *Er ist krank. Trotzdem geht er zur Arbeit.*

## 四、B1/B2：dennoch【书面】/ gleichwohl【书面·少用】/ nichtsdestotrotz【口语调侃】/ nichtsdestoweniger【书面·少用】— 书面让步副词【补充】

与 trotzdem 同属让步副词（正语序），但**语体更书面**，用于正式写作和新闻。

| 副词 | 语体 | 含义 | 例句 |
|------|------|------|------|
| **dennoch** | 书面、正式 | 然而、仍然 | Es regnete, **dennoch** gingen wir spazieren. |
| **gleichwohl** | 高度书面 | 尽管如此、仍然 | **Gleichwohl** müssen wir die Entscheidung akzeptieren. |
| **nichtsdestotrotz** | 口语/调侃（书面亦见） | 尽管如此 | **Nichtsdestotrotz** hat er das Rennen gewonnen. |
| **nichtsdestoweniger** | 高度书面 | 尽管如此 | **Nichtsdestoweniger** bleibt das Problem ungelöst. |

| 例句 | 翻译 |
|------|------|
| Die Aufgabe war schwer, **dennoch** haben wir sie gelöst. | 任务很难，但我们还是解决了。 |
| Er war müde; **gleichwohl** arbeitete er bis Mitternacht weiter. | 他很累，但尽管如此还是工作到半夜。 |
| Das Projekt scheiterte. **Nichtsdestotrotz** lernten wir viel daraus. | 项目失败了。尽管如此，我们从中收获很多。 |

> 📌 记忆：trotzdem（口语）→ dennoch（书面）→ gleichwohl / nichtsdestoweniger（高度书面）。**dennoch 是 trotzdem 的书面升级版**，考试写作用它加分。

> ⚠️ 语序同 trotzdem：`..., dennoch gehe ich spazieren.`（占位1，动词第二位，主语随后）——千万不能写 ~~dennoch ich gehe~~ ❌

## 五、B1/B2：obgleich【书面】/ obschon【书面·少用】/ wenngleich【书面】/ obzwar【近绝迹】— 书面语同义词【补充】

**规则**：obgleich 和 obschon 是 obwohl 的书面语同义词，用法完全相同（尾语序），但更正式，多用于文学、新闻、正式文体。

| 连词 | 语体 | 说明 |
|------|------|------|
| obgleich | 书面 | obwohl 的标准书面替代 |
| obschon | 书面/略带古旧 | 多用于文学、正式语 |
| wenngleich | 书面/新闻 | = obwohl，报纸杂志高频【补充】 |
| obzwar | 书面/地区性（奥地利） | = obwohl，较罕见【补充】 |

| 例句 | 翻译 |
|------|------|
| **Obgleich** die Prüfung sehr schwer **war**, haben alle Studenten sie bestanden. | 虽然考试很难，所有学生都通过了。 |
| Er ging zur Arbeit, **obschon** er sich unwohl **fühlte**. | 他去上班了，尽管他感觉不舒服。 |
| **Obgleich** er wenig Zeit **hatte**, half er uns allen. | 尽管他时间很少，他还是帮助了我们所有人。 |
| **Wenngleich** der Preis hoch ist, ist die Qualität ausgezeichnet. | 虽然价格高，但质量极好。（新闻常见） |
| **Obzwar** es regnete, kamen alle Gäste. | 尽管下雨，所有客人都来了。 |

> 📌 记忆技巧：gleich = 相同，schon = 已经 → 都可替代 obwohl。口语中几乎只用 obwohl，书面语/新闻中才出现 obgleich/obschon/wenngleich。

## 六、B1：zwar ... aber / doch【常用】/ zwar ... jedoch【书面】/ zwar ... dafür aber【常用】— "虽然……但是……"

**规则**：zwar 与 aber/doch 是**搭配使用的连词**。zwar 在主句中承认一个事实，aber/doch 引出转折；aber/doch 后接**正常语序主句**（非从句）。

| 结构 | 示例 |
|------|------|
| Zwar + 句子1, aber + 句子2 | *Zwar ist er krank, aber er geht zur Arbeit.* |
| 句子1 zwar, aber + 句子2 | *Er ist zwar krank, aber er geht zur Arbeit.* |

| 例句 | 翻译 |
|------|------|
| **Zwar** ist das Auto teuer, **aber** es ist sehr gut. | 虽然这辆车很贵，但它非常好。 |
| Sie spricht **zwar** langsam, **doch** sie spricht korrekt. | 她虽然说得很慢，但她说得很准确。（doch = aber，更书面） |
| **Zwar** habe ich viel gelernt, **aber** die Prüfung war trotzdem schwer. | 虽然我学了很多，但考试还是很难。 |

> 📌 zwar 可放句首，也可放句中（紧跟动词后）；aber 后面是正常语序，不是从句。

### zwar ... jedoch 【补充】

**jedoch** 是连接性副词（不是连词），后接**正语序**主句，可放第二位或句中第三位：

| 例句 | 翻译 |
|------|------|
| Er ist **zwar** reich, **jedoch** ist er unglücklich. | 他虽然富有，却不幸福。 |
| Sie hat **zwar** Talent, **jedoch** fehlt es ihr an Fleiß. | 她虽有天赋，却缺乏勤奋。 |

### zwar ..., dafür aber — 补偿性转折【补充】

**dafür** 表"但好在……/但作为补偿……"，指主句在另一维度上弥补前句的不足：

| 例句 | 翻译 |
|------|------|
| Er ist **zwar** klein, **dafür aber** sehr schnell. | 他虽然个子小，但非常快。 |
| Die Wohnung ist **zwar** teuer, **dafür** hat sie einen Balkon. | 房子虽贵，但好在有阳台。 |
| Sie ist **zwar** jung, **dafür aber umso** erfahrener. | 她虽然年轻，但反而更有经验。 |

> 💡 与 aber 的差别：**dafür** 引入的是"补偿性优点"而非"单纯转折"，口语论证常用，B2 写作加分项。

## 七、B1/B2：auch wenn【常用】/ selbst wenn【常用】/ sogar wenn【近绝迹】— 假设型让步（让步条件）

**规则**：表示"即使某个假设/条件存在，结果也不变"，带条件 + 让步双重含义，尾语序。

| 连词 | 语义 | 语气 | 例句 |
|------|------|------|------|
| wenn（条件） | 如 A 则 B | — | Wenn das Wetter schön ist, gehen wir raus. |
| auch wenn（让步） | 即使 A 仍 B | 中 | Auch wenn es regnet, gehe ich joggen. |
| selbst wenn（让步强调） | 纵使、哪怕 | 强 | Selbst wenn du mich anflehen würdest, würde ich nicht nachgeben. |

| 例句 | 翻译 |
|------|------|
| **Auch wenn** er viel Geld hat, ist er nicht glücklich. | 即使他有很多钱，他也不幸福。 |
| **Auch wenn** es spät ist, rufe ich sie noch an. | 即使很晚了，我还是要给她打电话。 |
| **Selbst wenn** du mir die halbe Welt schenken würdest, ich bliebe hier. | 就算你把半个世界给我，我也会留在这里。 |
| **Selbst wenn** es schneit, findet der Markt statt. | 哪怕下雪，集市也会照常举行。 |

> 💡 **sogar wenn**（= selbst wenn，罕见变体）【补充】：*Sogar wenn er sich entschuldigt, glaube ich ihm nicht.*（纵使他说抱歉，我也不信他。）

### obwohl vs. auch wenn 对比【辨析】

| | obwohl | auch wenn |
|---|---|---|
| 语义 | 事实让步（障碍是真实存在的） | 假设让步（障碍是假设/条件） |
| 中文 | 虽然……但是…… | 即使……也…… |
| 例句 | Obwohl es regnet, gehe ich. | Auch wenn es regnet, gehe ich. |

### auch wenn / selbst wenn + Konjunktiv II — 非现实让步【补充】

表示"即使（事实上不存在的）假设成立，结果仍不变"，二虚强调纯假设性：

| 例句 | 翻译 |
|------|------|
| **Auch wenn** ich genug Geld **hätte**, würde ich dieses Auto nicht kaufen. | 即使我有足够的钱，我也不会买这辆车。 |
| **Selbst wenn** er mich um Verzeihung **bäte**, würde ich ihm nicht verzeihen. | 哪怕他求我原谅，我也不会原谅他。 |
| **Auch wenn** das Wetter noch so schön **wäre**, würde ich zu Hause bleiben. | 即使天气再好，我也会待在家里。（K II 前后一致：wäre…würde） |

> 💡 记忆：**obwohl = 事实，auch wenn = 假设**。陈述真实困难用 obwohl；举假设反例、让步条件用 auch wenn / selbst wenn（后者语气最强，"哪怕""纵使"）。

## 八、B1/B2：wenn ... auch【文学/陈旧】/ wenn schon【常用习语】— "即使……也……" 让步 wenn 家族

### wenn ... auch — "即使……也……"

**规则**：与 auch wenn 同源但侧重不同——wenn...auch 常用于**承认一个事实仍坚持主句**，文学作品或较正式文体多见。

| 例句 | 翻译 |
|------|------|
| **Wenn** es **auch** schwer ist, ich gebe nicht auf. | 即使很难，我也不会放弃。 |
| **Wenn** er **auch** viel Geld hat, er ist nicht glücklich. | 即使他有很多钱，他也不幸福。 |
| **Wenn** die Arbeit **auch** langweilig ist, ich brauche das Geld. | 即使这工作很无聊，我也需要钱。 |

### wenn auch 的省略式【补充】

主句在前，让步内容以短语形式补充（wenn auch = 尽管……，哪怕……）：

| 例句 | 翻译 |
|------|------|
| Er kam zur Party, **wenn auch** erst spät. | 他来参加聚会了，尽管到得很晚。 |
| Die Lösung ist gut, **wenn auch** nicht perfekt. | 这个方案很好，尽管不完美。 |

> ⚠️ **wenn auch vs. auch wenn**：连用顺序不同，语义重心不同——**wenn auch** 承认部分成立（"即便这样"），**auch wenn** 强调假设条件（"即使那样也"）。两者都与尾语序兼容。

### wenn schon ... dann (schon) — "既然……那就"（已学于条件专栏，回顾）

表示"既然 A 成立/既然要做，就干脆做 B"，带让步 + 条件混合味：

| 例句 | 翻译 |
|------|------|
| **Wenn schon**, denn schon! | 要做就做到位！/一不做二不休。（习语） |
| **Wenn schon** nicht nach Deutschland, dann wenigstens nach Österreich. | 既然不是去德国，那至少去奥地利。 |

### wenn (auch) nicht ... so doch — 双重否定强调【补充】

"即使……不完美，也（毕竟）……"，让步中带折中肯定：

| 例句 | 翻译 |
|------|------|
| **Wenn** es **auch nicht** perfekt ist, **so** ist es **doch** sehr gut. | 即使不完美，也算很不错了。 |
| **Wenn** er **auch nicht** reich ist, **so** ist er **doch** zufrieden. | 即使他不富有，也过得挺满足。 |

## 九、B2：so + Adjektiv/Adverb + auch【书面·常用，考试重点】— "无论多么……"

**规则**：地道的 B2 让步结构，表达"无论多么……也……"。so 后面紧跟形容词或副词，auch 位于主语和动词之间，从句尾语序（动词在句末）。

**两种语序**（写法不同，语义相同）：

| 版本 | 公式 | 例 |
|:--:|------|------|
| A（从句式）| So + Adj + 主语 + ... + auch + 动词**末尾** | So schwer es auch **ist**, ... |
| B（倒装式）| So + Adj + 动词**二位** + 主语 + ... + auch | So schwer **ist** es auch, ... |

| 例句 | 翻译 |
|------|------|
| **So** teuer das Auto **auch** ist, ich kaufe es. | 无论这辆车多贵，我都要买。 |
| **So** müde er **auch** war, er konnte nicht schlafen. | 无论他多累，他都睡不着。 |
| **So** oft ich es **auch** versuche, ich kann es nicht verstehen. | 无论我尝试多少次，我都无法理解。（auch 修饰频率副词 oft） |
| **So** schön das Angebot **auch** klingt, ich lehne ab. | 无论这个提议听起来多好，我都拒绝。 |
| **So** klug er **auch** ist, er macht Fehler. | 无论他多聪明，也会犯错。 |

> 📌 记忆：**so + 形容词 + 主语 + auch + 动词末尾**——"无论多 X 也……"。

## 十、B2：wie + Adj. + auch【书面/文学】/ so sehr ... auch【书面】/ ... auch immer【书面】— 变体【补充】

### wie + Adjektiv + auch — "无论多么……"

与 so...auch 同义，但引导词换成 wie，更文学化、强调更强：

| 例句 | 翻译 |
|------|------|
| **Wie** schwierig es **auch** ist, wir schaffen es. | 无论多难，我们都能做到。 |
| **Wie** teuer das Buch **auch** sein mag, ich kaufe es. | 无论这本书多贵，我都要买。 |

### so sehr ... auch — "无论如何……也"

强调程度（sehr 替代具体形容词），常用于"努力/期待/喜爱"等抽象程度：

| 例句 | 翻译 |
|------|------|
| **So sehr** ich mich **auch** bemühe, ich schaffe es nicht. | 无论我多努力，都做不到。 |
| **So sehr** ich ihn **auch** mag, ich kann ihm nicht verzeihen. | 无论我多喜欢他，我都没法原谅他。 |
| **So sehr** er sich **auch** ärgert, es ändert nichts. | 无论他多生气，都无济于事。 |

### ... auch immer — 让步不定式加强【补充】

在 so/wie 结构后加 **immer** 或与 **mag** 连用，语气更强，表"无论再怎么……"：

| 例句 | 翻译 |
|------|------|
| **Wie** sehr es **auch immer** regnet, das Konzert findet statt. | 无论雨下得多大，演唱会照常举行。 |
| **So** teuer es **auch immer** sein mag, es lohnt sich. | 无论多贵，都值得。 |

> 💡 这三个变体 + so...auch 是"无论多么"家族：`so + Adj + auch`（基础）→ `wie + Adj + auch`（文学）→ `so/wie + sehr + auch (immer)`（程度加强）。

## 十一、B2：noch so + Adjektiv【常用】— "再怎么……也……"

**规则**：与 so...auch 类似，但语气更强，强调"再怎么……也无济于事"，带无奈感。动词常用尾语序，也可用主句语序。

| 例句 | 翻译 |
|------|------|
| Er ist **noch so** reich, er kann sich das nicht leisten. | 他再怎么有钱，也买不起这个。 |
| **Noch so** viel Lernen hilft nichts, wenn man nicht übt. | 再怎么多学也没用，如果不练习的话。 |
| Sie war **noch so** vorsichtig, der Unfall passierte trotzdem. | 她再怎么小心，事故还是发生了。 |
| **Noch so** fleißig könnte er nicht alles schaffen. | 他再怎么勤快也完成不了所有事。 |

> 📌 记忆：**noch so = "再怎么……也没用"**——语气最强，带无奈、强调无济于事。

---

## 十二、B2：mögen 让步【书面·少用】/ mochte【文学/陈旧】— 让步情态动词【补充】

**规则**：用情态动词 mögen 表达"就算/即使……也"，后接**不定式在句末**，主句陈述不受影响的结果。表让步时语气书面、委婉。

| 例句 | 翻译 |
|------|------|
| Er **mag** noch so reich sein, glücklich ist er nicht. | 他就算再有钱，也不幸福。 |
| Er **mag** Recht haben, aber ich stimme ihm nicht zu. | 他也许是对的，但我不同意他。 |
| **Mögen** die Gegner es noch so versuchen, wir geben nicht nach. | 就算对手再怎么尝试，我们也不让步。 |
| **Mag** es regnen oder schneien, wir gehen wandern. | 无论下雨还是下雪，我们都去远足。 |

> 💡 变体【补充】：① **mochte**（Präteritum，文学/书面）：*Mochte er auch noch so bitten, sie blieb hart.*（任凭他如何恳求，她依然心硬。）② 口语让步承认：*Das mag ja alles sein, aber ich bleibe dabei.*（也许这一切都对，但我坚持己见。）

> 📌 记忆：**mögen 让步 = "就算……也"**，常与 noch so 搭配（mögen + noch so + Adj.），是 B2 书面让步的标志结构。

---

## 十三、B2：egal【常用】/ einerlei【书面·少用】/ gleichgültig【书面】/ wurscht【口语】+ 疑问词 — "不管……"

**规则**：口语和书面语都常用，表达"无论/不管……都……"。egal 可搭配全部 W-Wort（wer/was/wie/wann/wo/warum）。

| 搭配 | 含义 |
|------|------|
| egal wer | 不管是谁 |
| egal was | 不管是什么 |
| egal wie | 不管怎样 |
| egal wann | 不管什么时候 |
| egal wo | 不管在哪里 |
| egal warum | 不管为什么 |

| 例句 | 翻译 |
|------|------|
| **Egal was** er sagt, ich glaube ihm nicht. | 不管他说什么，我都不信他。 |
| **Egal wie** sehr ich mich anstrenge, es reicht nicht. | 不管我多努力，都不够。 |
| **Egal wann** du kommst, ich bin zu Hause. | 不管你什么时候来，我都在家。 |
| **Einerlei was** passiert, wir bleiben zusammen. | 无论发生什么，我们都在一起。（einerlei 更书面） |
| Das ist mir **egal**. | 这对我来说无所谓。（独立使用，口语高频） |

### 同义替换【补充】

| 表达 | 语体 | 例句 |
|------|------|------|
| **gleichgültig + W-Wort** | 书面 | **Gleichgültig, was** er sagt, ich bleibe dabei. |
| **wurscht/wurst + W-Wort** | 口语（俗） | **Wurscht, was** du denkst, ich mache es so. |
| **ob ... (egal) oder** | 通用 | **Ob du willst oder** nicht, wir müssen gehen. |

> 📌 记忆：egal 是最口语化的"不管"；einerlei/gleichgültig 是书面替换；wurscht 是俗语。W-Wort 后接尾语序小句：`Egal, was er sagt, ...`。

---

## 十四、B2：W-Wort + auch (immer)【书面】/ + K I 搭配【文学/陈旧】— "无论谁/什么/怎样"【补充】

**规则**：疑问词 + auch / auch immer 构成让步关系从句，表"无论……都"，尾语序，比 egal + W-Wort 更书面、更强调。

| 引导词 | 含义 | 例句 |
|------|------|------|
| **wer auch (immer)** | 无论谁 | **Wer auch immer** anruft, ich bin nicht zu Hause. |
| **was auch (immer)** | 无论什么 | **Was auch immer** passiert, wir bleiben ruhig. |
| **wie auch (immer)** | 无论怎样 | **Wie auch immer** du dich entscheidest, ich unterstütze dich. |
| **wann auch (immer)** | 无论何时 | **Wann auch immer** du Zeit hast, komm vorbei. |
| **wo auch (immer)** | 无论何地 | **Wo auch immer** du bist, ich vermisse dich. |
| **warum auch (immer)** | 无论为何 | **Warum auch immer** er das getan hat, es ist unverzeihlich. |

| 例句 | 翻译 |
|------|------|
| **Wer auch** das getan hat, er muss sich melden. | 无论是谁干的，他必须站出来。 |
| **Was auch** kommt, wir halten zusammen. | 无论发生什么，我们都团结在一起。 |
| **Wie auch immer** das ausgeht, wir bleiben Freunde. | 无论结果如何，我们还是朋友。 |

> 💡 **egal + W-Wort（口语）↔ W-Wort + auch immer（书面）**对比：`Egal, was passiert, ...` = `Was auch (immer) passiert, ...`，两者语义相同，语体不同。
> ⚠️ 动词位置：W-Wort + auch 引导的小句**尾语序**（动词在末尾）——`Was auch immer passiert, ...`，不能写 ~~was auch immer es passiert~~ ❌
> 📌 B2 进阶【补充】：W-Wort + auch immer 可与 **Konjunktiv I**（间接引语/不确定）搭配：*Wer auch immer das behauptet haben mag, es ist nicht bewiesen.*（无论这话是谁说的，都未得到证实。）

---

## 十五、B2：ob ... oder【常用】/ ob nun ... oder【书面】— "无论……还是……"【补充】

**规则**：表"不管是否满足该条件/不管是哪种情况"，结果不变，带让步性质。可省略 ob 只用选择项。尾语序。

| 例句 | 翻译 |
|------|------|
| **Ob** du willst **oder** nicht, wir müssen gehen. | 无论你想不想，我们都得走。 |
| **Ob** es regnet **oder** die Sonne scheint, wir treffen uns um 10 Uhr. | 不管下雨还是出太阳，我们 10 点见。 |
| **Ob** er kommt **oder** nicht, die Party findet statt. | 不管他来不来，聚会照常举行。 |
| **Ob nun** groß **oder** klein, alle sind willkommen. | 无论大小，都欢迎。（nun 加强语气） |
| **Ob zu** Hause **oder** im Büro, er arbeitet immer. | 无论在家还是在办公室，他总是在工作。 |

> 📌 记忆：**ob...oder = "无论……还是……"**，常省略连词 ob：`Regen oder Sonnenschein, das Fest findet statt.`

---

## 十六、B2：sei es ... oder【书面】/ sei es dass ... sei es dass【近绝迹】— "无论是……还是……"

**规则**：用 Konjunktiv I（命令式同形）表达让步，高度书面，常用于枚举两个（或多个）并列可能性。

| 例句 | 翻译 |
|------|------|
| **Sei es** durch Fleiß **oder** durch Talent, er hat Erfolg. | 无论是通过勤奋还是天赋，他都会成功。 |
| **Sei es** Regen **oder** Sonnenschein, das Spiel findet statt. | 无论下雨还是晴天，比赛照常进行。 |
| **Sei es** im Beruf **oder** im Privatleben, Pünktlichkeit zählt. | 无论在职场上还是私生活中，守时都很重要。 |

### 变体：sei es dass ... sei es dass ...【补充】

枚举两个原因/可能性，极正式：

| 例句 | 翻译 |
|------|------|
| **Sei es dass** er krank ist, **sei es dass** er keine Lust hat – er kommt nicht. | 无论是他病了，还是他没兴趣——他都不来。 |
| **Sei es dass** wir es eilig haben, **sei es dass** wir uns verfahren haben, wir sind spät dran. | 不管是我们赶时间，还是迷路了，我们都要迟到了。 |

---

## 十七、B2：Konjunktiv I 让步固定式 — Wie dem auch sei【常用】/ Komme was wolle【文学/陈旧】/ Was auch kommen mag【文学/陈旧】【补充】

**规则**：用 K I 的固定表达让步，高度书面，常见于演讲、文学、正式书面语。

| 固定式 | 含义 | 例句 |
|------|------|------|
| **Komme was wolle** | 无论如何、随它怎样 | **Komme was wolle**, ich bleibe hier. |
| **Wie dem auch sei** | 无论如何、不管怎样 | **Wie dem auch sei**, wir müssen handeln. |
| **Was auch kommen mag** | 无论发生什么 | **Was auch kommen mag**, wir halten zusammen. |

| 例句 | 翻译 |
|------|------|
| **Komme, was wolle**, wir bleiben vereint. | 无论发生什么，我们都团结一致。 |
| **Wie dem auch sei**, die Entscheidung steht. | 不管怎样，决定已经定了。 |
| **Was auch kommen mag**, ich habe keine Angst. | 无论发生什么，我都不怕。 |

> 📌 记忆：这三个是 K I 让步的"成语式"结构，**整体背下来**即可，不可拆解改写。

## 十八、B1/B2：让步介词与名词化表达（trotz【常用】/ ungeachtet【书面·少用】/ bei allem【书面】/ allen...zum Trotz【文学/陈旧】/ entgegen【书面】/ wider Erwarten【常用】/ unbeschadet【法律公文】）

除了从句，德语还有介词和名词化的让步表达（书面语重要能力）。

### 1. trotz + Gen. — "尽管……"（B1）

**从句 → 介词短语转换**（名物化三步法：找动词→派生名词→加 Genitiv/Possessiv）：

| 从句 | 介词短语 |
|------|----------|
| Obwohl das Wetter schlecht ist, ... | **Trotz** des schlechten Wetters ... |
| Obwohl er krank war, ... | **Trotz** seiner Krankheit ... |
| Obwohl die Gefahr groß war, ... | **Ungeachtet** der großen Gefahr ... |
| Obwohl es regnet, ... | **Trotz** des Regens ... |

| 例句 | 翻译 |
|------|------|
| **Trotz** seiner Krankheit ging er zur Arbeit. | 尽管生病了，他还是去上班。（= Obwohl er krank war, ...） |
| **Trotz** des schlechten Wetters blieben wir zu Hause. | 尽管天气不好，我们还是待在家里。 |

> 📌 口语中 trotz 常接 Dativ（trotz dem Wetter），但书面语/考试要求 **Genitiv**（trotz des Wetters）。

### 2. trotz allem / trotz aller + 名词【补充】

| 例句 | 翻译 |
|------|------|
| **Trotz allem** liebe ich dich. | 尽管一切，我仍爱你。 |
| **Trotz aller** Schwierigkeiten haben wir es geschafft. | 尽管困难重重，我们还是做到了。 |

> 📌 trotz allem 是固定形式（allem 为中性 Dativ），表"尽管这一切"。
> 📌 **trotz alledem**（= trotz allem，更书面）【补充】：*Trotz alledem liebten sie sich.*（尽管发生了一切，他们仍相爱。）

### 3. ungeachtet + Gen. — "不顾/不管……"（B1/B2）

| 例句 | 翻译 |
|------|------|
| **Ungeachtet** der Schwierigkeiten hat sie es geschafft. | 不顾重重困难，她做到了。 |
| **Ungeachtet** der Gefahr half er dem Verletzten. | 不顾危险，他救助了伤者。 |

> 📌 ungeachtet 也可**后置**（正式）【补充】：*des Risikos ungeachtet*（不顾风险）

### 4. dessen ungeachtet — "尽管如此"（书面）【补充】

独立副词式用法，连接前文：

| 例句 | 翻译 |
|------|------|
| Der Plan ist riskant. **Dessen ungeachtet** fahren wir los. | 计划有风险。尽管如此，我们还是出发了。 |

### 5. bei allem / bei aller + Dat. — "尽管……一切"（B1/B2）

| 例句 | 翻译 |
|------|------|
| **Bei allem** Verständnis, dein Vorschlag ist nicht realistisch. | 尽管我能理解，但你的提议不现实。 |
| **Bei allem** Respekt, das halte ich für falsch. | 恕我直言，我认为这是错的。 |
| **Bei aller** Liebe zur Musik kann ich nachts nicht üben. | 尽管我热爱音乐，我夜里也不能练。（bei aller + Adj. + 名词） |

### 6. allen ... zum Trotz — "不顾……仍……"（B2）【补充】

**规则**：名词用 Dativ 复数（或不可数），zum Trotz 置于名词后：

| 例句 | 翻译 |
|------|------|
| **Allen Widrigkeiten zum Trotz** haben wir das Ziel erreicht. | 不顾一切艰难险阻，我们达成了目标。 |
| **Dem Regen zum Trotz** gingen wir spazieren. | 不顾下雨，我们还是去散步了。 |

### 7. entgegen + Dat. — "与……相反，尽管"（B2 正式）【补充】

表"与预期/建议相反"的让步式对立：

| 例句 | 翻译 |
|------|------|
| **Entgegen** meiner Erwartung bestand er die Prüfung. | 与我的预期相反，他通过了考试。 |
| **Entgegen** allen Ratschlägen hat sie geheiratet. | 不顾所有人的劝告，她结婚了。 |

### 8. wider Erwarten — "出乎意料地"（B2）【补充】

固定短语，表"与预期相反，竟……"：

| 例句 | 翻译 |
|------|------|
| **Wider Erwarten** wurde das Projekt ein Erfolg. | 出乎意料地，项目竟然成功了。 |
| Er kam **wider Erwarten** pünktlich. | 他出乎意料地准时来了。 |

> 💡 同义【补充】：**gegen alle Erwartungen**（= wider Erwarten，同样常用）：*Gegen alle Erwartungen gewann die Mannschaft.*（出乎所有人意料，球队赢了。）

### 9. unbeschadet + Gen. — "不妨碍……，尽管"（B2+ 正式/法律）【补充】

| 例句 | 翻译 |
|------|------|
| **Unbeschadet** der Differenzen arbeiten sie weiter zusammen. | 尽管存在分歧，他们仍继续合作。 |
| **Unbeschadet** der Ergebnisse bleibt die Frage offen. | 无论结果如何，这个问题仍悬而未决。 |

## 十九、B2：obwohl + Konjunktiv II【书面，仍在使用】— 让步与现实反事实【补充】

**规则**：当让步从句里的内容**本可以/本应该发生但没发生**时，用 K II（hätte/wäre können 等），表达"尽管（本可以）……却……"的遗憾/对比意味。

| 例句 | 翻译 |
|------|------|
| Sie fuhr mit dem Taxi, **obwohl** sie den Bus **hätte nehmen können**. | 尽管她本可以坐公交，却坐了出租车。 |
| Er ging zur Arbeit, **obwohl** er zu Hause **hätte bleiben können**. | 尽管他本可以待在家，他还是去上班了。 |
| **Obwohl** er es besser **hätte wissen müssen**, hat er den Fehler gemacht. | 尽管他本应该更明白，却犯了那个错。 |

> 💡 对比：`obwohl + Indikativ`（陈述事实障碍）vs `obwohl + K II`（障碍是"本可能但未发生"的情况）。后者是 B2 书面表达遗憾、对比的进阶手段。

## 二十、让步相关核心词汇【补充】

| 词汇 | 词性 | 含义 | 例句 |
|------|------|------|------|
| die Konzession, -en | 阴性 | 让步 | Er machte eine **Konzession**.（他做了让步。） |
| konzessiv | 形容词 | 让步的（语法术语） | Der **konzessive** Nebensatz ... |
| einräumen (räumte ein / eingeräumt) | 动词 | 承认、让步 | Ich **räume** ein, dass du recht hast. |
| das Zugeständnis, -se | 中性 | 让步（名词） | Beide Seiten machten **Zugeständnisse**. |
| zugestehen (gestand zu / zugestanden) | 动词 | 承认、允予 | Ich **gestehe** ihm das Recht zu. |
| trotzdem（副词） | — | 尽管如此 | Er kam **trotzdem**. |

> 📌 写作提分："做出让步" = eine Konzession machen / Zugeständnisse machen；"承认错误" = einen Fehler einräumen。

| B2 | ob ... oder (nun) 【补充】 | 无连词语序变化 | 通用 | 无论……还是…… |
| B2 | sei es ... oder | K I | 高度书面 | 无论是……还是…… |
| B2 | Komme was wolle / Wie dem auch sei 【补充】 | K I 固定式 | 高度书面 | 无论如何 |
| B2 | ungeachtet + Gen. / dessen ungeachtet | 介词短语 | 正式/书面 | 不顾/尽管如此 |
| B2 | allen ... zum Trotz 【补充】 | 介词短语 | 书面 | 不顾……仍…… |
| B2 | entgegen + Dat. 【补充】 | 介词短语 | 正式 | 与……相反 |
| B2 | wider Erwarten 【补充】 | 固定短语 | 书面 | 出乎意料地 |
| B2 | obwohl + K II 【补充】 | 动词末尾 | 书面 | 尽管（本可以……） |

**同一让步语义的四种表达（改写练习核心）**：
`Obwohl es regnet, gehe ich hinaus.`
= `Es regnet. Trotzdem gehe ich hinaus.`
= `Zwar regnet es, aber ich gehe hinaus.`
= `So sehr es auch regnet, ich gehe hinaus.`
= `Trotz des Regens gehe ich hinaus.`

## 二十三、常见错误提醒（Fehlerquelle）

| 错误 | 正确 | 说明 |
|------|------|------|
| Obwohl es regnet, **aber** ich gehe. | Obwohl es regnet, **gehe** ich. | obwohl 与 aber 不能连用 |
| Trotzdem **er krank ist**, geht er. | **Obwohl** er krank ist, geht er. | trotzdem 不引导从句，需用 obwohl |
| dennoch ich komme | dennoch **komme** ich | dennoch 是副词，后接正语序 |
| Zwar ist er krank, **aber** geht er. | Zwar ist er krank, **aber** er geht. | aber 后是正常主句，动词第二位 |
| So schwer **auch er es** findet, ... | **So schwer er es auch** findet, ... | auch 通常位于主语之后 |
| Auch wenn es regnet, **aber** ich gehe. | Auch wenn es regnet, gehe ich. | auch wenn 同样不能与 aber 连用 |
| Egal, was **sagt** er, ich glaube ihm nicht. | Egal, was er **sagt**, ich glaube ihm nicht. | egal + W-Wort 从句尾语序（动词在末尾） |
| Was **passiert** auch immer, wir bleiben ruhig. | Was auch immer **passiert**, wir bleiben ruhig. | auch immer 紧跟 W-Wort，动词仍在句末 |
| während（对比）误用于让步 | obwohl / auch wenn | während 是对立，obwohl 是让步 |
| obwohl + Indikativ 用于"本可能"情况 | obwohl + **hätte ... können** | 反事实需 K II |

## 二十四、记忆技巧

1. **obwohl = 踢**（动词踢到末尾）— 最常用，口语首选
2. **trotzdem = 顶回去**（"尽管如此"仍……）— 副词，主句语序；书面升级 = dennoch
3. **obgleich / obschon / wenngleich = 书面替补** — 写作/新闻中的 obwohl
4. **zwar...aber = 先承认后转折** — "虽然……但是……"最接近中文语感
5. **obwohl = 事实，auch wenn = 假设** — 真实障碍 vs 假设条件
6. **selbst wenn = 语气最强** — "哪怕、纵使"，常配 K II
7. **so...auch = 无论多么** — so 后接形容词，auch 放主语后；变体 wie + Adj. + auch
8. **noch so = 再怎么也没用** — 语气最强，带无奈感
9. **mögen = 就算……也** — 书面让步情态，常与 noch so 连用
10. **egal + W-Wort = 不管怎样** — 最口语化的"不管"；书面版 = W-Wort + auch immer
11. **ob...oder / sei es...oder = 无论……还是** — 枚举两种可能
12. **介词短语 = 名词化** — trotz + Gen. 是书面语中 obwohl 从句的替代
13. **中德思维差异**：德语让步从句不需要"但是"（aber），这是与中文最大的不同

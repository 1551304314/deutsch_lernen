## 一、Konsekutivsätze 概念与核心认知

回答 **Was ist die Folge? / Welches Ergebnis hat das?（结果是什么？）**，说明主句行为**带来的实际后果**。

### 五大类表达手段总览

| 类型 | 连接手段 | 语序 |
|------|----------|------|
| 从属连词（Nebensatz） | sodass, so...dass, solch-...dass, derart...dass, dermaßen...dass, (zu...) als dass | 动词末尾（尾语序） |
| 不定式结构 | zu + Adj. + um...zu; Adj. + genug + um...zu | 无主语，zu + 不定式在句末 |
| 连接性副词（Konjunktionaladverb） | also, folglich, infolgedessen, demnach, somit, mithin | 正语序（占位1，动词第二位） |
| 介词短语（名物化） | infolge + Gen., zufolge + Dat.（后置） | 无动词，名词化结构 |
| 动词短语 | zur Folge haben, führen zu, dazu führen, dass | 主句 + 尾语序 |

### ⭐ 结果 vs 目的 —— 贯穿全专题的主线【已学 08-07】

| | 结果从句 sodass | 目的从句 um...zu / damit |
|------|------|------|
| 语义 | **客观结果**（已经发生/必然发生） | **主观意图**（尚未发生，想达到） |
| 提问 | Was ist die Folge? | Wozu? Wofür? |
| 例句 | Er lernte viel, **sodass** er die Prüfung bestand. | Er lernt viel, **um** die Prüfung zu bestehen. |
| 中文 | 他学了很多，所以通过了考试。 | 他学很多，是为了通过考试。 |

> 💡 判断法：句子说"所以/结果怎样"→ 结果从句；句子说"为了/目的"→ 目的从句。

## 二、A2：zu + Adj. + um...zu — "太……而不能"【常用】【已学 05-15】

**规则**：zu + 形容词/副词，后接 um...zu + 不定式（无主语）。**不定式逻辑主语必须与主句主语一致**。表"太……以至于不能做……"。

| 例句 | 翻译 |
|------|------|
| Es ist **zu kalt**, **um zu** schwimmen. | 天太冷了，不能游泳。 |
| Ich bin **zu müde**, **um** weiterzuarbeiten. | 我太累了，没法继续工作。 |
| Das Buch ist **zu schwierig**, **um** es an einem Tag zu lesen. | 这本书太难了，没法一天读完。 |

> ⚠️ 两个 zu 都别漏：形容词前的 **zu（太）** 和不定式前的 **zu**（um **zu** schwimmen，不是 ~~um schwimmen~~ ❌）。
> ⚠️ 主语必须一致：主句主语就是不定式动作的施动者。

---

## 三、A2/B1：Adj. + genug + um...zu — "足够……可以"【常用】【已学 05-15】

**规则**：**形容词放在 genug 前面**（alt genug，不是 ~~genug alt~~ ❌），后接 um...zu + 不定式，表"足够……以至于可以……"。也可用 genug + 名词（genug 前置）。

| 例句 | 翻译 |
|------|------|
| Er ist **alt genug**, **um** allein zu reisen. | 他足够大了，可以独自旅行。 |
| Das Wasser ist **warm genug**, **um** zu schwimmen. | 水够暖，可以游泳。 |
| Sie hat **genug Geld**, **um** sich ein Auto zu kaufen. | 她有足够的钱买一辆车。 |

> 📌 记忆：**形容词在前，genug 在后**（alt genug）；但 **genug + 名词在前**（genug Geld）。对比中文"足够大"，语序正好相反！
> ⚠️ genug 的否定：**nicht genug ... um zu**（"不够……而不能"），否定词在 genug 前：Er ist **nicht** alt **genug, um** Auto zu fahren. 他还不到能开车的年龄。

## 四、B1：sodass — "所以 / 以至于"【常用】【已学 05-15 / 08-07】

**规则**：sodass 是从属连词，动词末尾（尾语序）。**不能放句首**（与 denn 同理）。可拆写成 **so dass**（两种写法都对，sodass 更现代统一）。

| 例句 | 翻译 |
|------|------|
| Er kam zu spät, **sodass** er den Zug verpasste. | 他来晚了，所以错过了火车。 |
| Es regnete stark, **sodass** das Spiel abgesagt wurde. | 雨下得很大，所以比赛被取消了。 |
| Sie sprach sehr schnell, **so dass** niemand sie verstehen konnte. | 她说得很快，以至于没人能听懂。 |

> ⚠️ 常见错误：~~Sodass wir zu Hause blieben, es regnete~~ ❌ — sodass 不能置句首。
> 💡 与因果副词互通：sodass 从句 ≈ 主句 + 结果副词（见第八节）。

---

## 五、B1：so + Adj./Adv. + dass — "如此……以至于"【常用】【已学 05-15 / 08-07】

**规则**：so + 形容词/副词（强调程度），后接 dass 从句（尾语序），表"如此……以至于……"。

| 例句 | 翻译 |
|------|------|
| Der Film war **so langweilig**, **dass** ich einschlief. | 电影太无聊了，以至于我睡着了。 |
| Er war **so müde**, **dass** er sofort einschlief. | 他那么累，立刻就睡着了。 |
| Es war **so** kalt, **dass** wir zu Hause blieben. | 天那么冷，我们待在了家里。 |

**程度副词扩展**（so 可替换为数量/强度词）【补充】：

| 结构 | 例 |
|------|-----|
| so + Adj. | so groß, so schnell, so teuer |
| so viel / so viele | Er hat **so viel** Arbeit, dass er keine Pause hat. |
| so sehr | Ich liebe dich **so sehr**, **dass** ich ohne dich nicht leben kann. |
| so lange | Er blieb **so lange**, **dass** alle müde wurden. |

> ⚠️ **so...dass（结果）vs so...wie（比较）**：so...wie = 比较（"和他一样高"）；so...dass = 结果（"如此……以至于"）。只有搭配 dass 才是结果从句。
> ⚠️ dass 从句动词必须落尾：...dass ich einschlief（einschlief 已在末尾）。

### 辨析：so...dass（结果实际发生）vs zu...um zu（限度被突破，必为"不能"）【补充】

| | so + Adj. + dass | zu + Adj. + um...zu |
|------|------|------|
| 语义 | 结果**确实发生**，正负皆可 | 结果**不能发生**，必为否定结果 |
| 例 | Er war **so** fit, **dass** er den Marathon schaffte. 他状态那么好，跑完了马拉松。（正结果） | Er war **zu** müde, **um** zu arbeiten. 他太累了，没法工作。（负结果） |
| 例 | Sie ist **so** krank, **dass** sie nicht kommen kann. | Sie ist **zu** krank, **um** zu kommen. |

> 📌 语义接近时二者可互换：so schwach, **dass** er nicht stehen kann ≈ **zu** schwach, **um** zu stehen。

## 六、B2：solch- + Nomen + dass — "这样的……以至于"【书面】【补充】

**规则**：so...dass 修饰**形容词/副词**；当要强调**名词**本身的程度时，改用 **solch-**（如此、这样的）修饰名词，后接 dass 从句。是 so...dass 的"名词版"，B2 书面写作高频。

### solch- 的两种位置（变格）

| 位置 | 结构 | 例 |
|------|------|-----|
| 前置 + 不定冠词 | solch ein + N / solch eine + N / solch ein + N | **solch ein** Problem |
| 后置 + 不定冠词 | ein **solcher** / eine **solche** / ein **solches** + N | ein **solches** Problem |
| 复数（无冠词） | solche + N（词尾 -e） | **solche** Probleme |

> 📌 规律：solch- 的变格与 **dieser/jener** 或形容词变格同类——带不定冠词时词尾按 **形容词强变化**（solcher/solche/solches）。

### 例句

| 例句 | 翻译 |
|------|------|
| Er hat **solchen Hunger**, **dass** er nicht mehr gehen kann. | 他饿得（如此之饿）走不动路了。 |
| Es gab **solche Probleme**, **dass** das Projekt gestoppt wurde. | 出现了那样的问题，项目被叫停了。 |
| Sie hat **solche Angst**, **dass** sie nicht schlafen kann. | 她害怕得睡不着觉。 |
| Es war **ein solches** Chaos, **dass** niemand den Überblick hatte. | 混乱得没人能理出头绪。 |

### so ein/eine + N + dass（口语版）【常用】【补充】

口语中常用 **so ein** 代替 solch ein（"这么一个/那么一个"）：

| 例句 | 翻译 |
|------|------|
| Er hat **so einen** Hunger, dass er alles aufisst. | 他饿得把什么都吃光。 |
| Ich hatte **so eine** Angst, dass ich weglief. | 我吓得逃跑了。 |

> 📌 辨析：**so + Adj.（修饰形容词）** vs **solch- / so ein + N（修饰名词）**：
> - so **hungrig**, dass...（hungrig 是形容词）✅
> - solchen **Hunger**, dass...（Hunger 是名词）✅
> - ~~so Hunger~~ ❌（so 不能直接修饰名词，需 so **einen** Hunger 或 solchen Hunger）

## 七、B1/B2：zu + Adj. + als dass + Konjunktiv II — "太……以至于不能"【书面】【已学 05-15】

**规则**：与 zu...um...zu 意思相同（都是"太……不能"），但：
1. **主语可以不同**（是完整从句，有自己主语）
2. **从句必须用 Konjunktiv II**（结果未实现，虚拟语气）

| 例句 | 翻译 |
|------|------|
| Es ist **zu kalt**, **als dass** man schwimmen **könnte**. | 天太冷了，没法游泳。（主语不同：es / man） |
| Die Aufgabe ist **zu schwer**, **als dass** ich sie lösen **könnte**. | 任务太难，我解不出来。 |
| Er ist **zu müde**, **als dass** er noch weiterarbeiten **könnte**. | 他太累了，没法继续工作了。 |

### zu...um...zu vs zu...als dass 对比

| | zu + Adj. + um...zu | zu + Adj. + als dass + KII |
|------|------|------|
| 主语 | 必须一致（无主语） | 可以不同 |
| 动词 | zu + 不定式 | 完整从句 + 变位动词（KII） |
| 级别 | A2 | B1/B2 |
| 例 | Es ist zu kalt, **um zu schwimmen**. | Es ist zu kalt, **als dass** man schwimmen **könnte**. |

> ⚠️ 高频错误：
> - ~~zu kalt, als dass man schwimmen **kann**~~ ❌ → **könnte** ✅（必须 KII）
> - ~~zu kalt, dass man nicht schwimmen kann~~ ❌ → 不能把 als dass 换成 dass

## 八、B1：derart / dermaßen + dass — "如此 / 这般……以至于"【书面·少用】【补充】

**规则**：derart / dermaßen（如此、这般）强调程度，后接 dass 从句。比 so...dass 更书面、语气更强；日常口语用 so...dass 即可。

| 例句 | 翻译 |
|------|------|
| Es war **derart** laut, **dass** wir nichts verstehen konnten. | 那么吵，我们什么都听不见。 |
| Sie war **dermaßen** aufgeregt, **dass** sie nicht sprechen konnte. | 她激动得说不出话来。 |
| Der Verkehr war **derartig** stark, **dass** wir zwei Stunden brauchten. | 交通那么堵，我们花了两小时。 |

> ⚠️ 认识即可，主动输出请优先用 **so...dass**。

## 九、B1：结果副词家族（Konsekutivadverbien）【补充】

**规则**：连接两个主句，副词占位1，**动词第二位**（正语序），主语随后。与 sodass 表达相同的"结果"语义，书面等级递进。

| 副词 | 含义 | 语体 |
|------|------|------|
| also | 所以、于是 | 口语【常用】 |
| folglich | 因此、因而 | 【书面】 |
| infolgedessen | 因此（字面"出于此结果"） | 【书面】 |
| demnach | 由此可见、因此 | 【书面】 |
| dementsprechend | 相应地、据此 | 【书面】 |
| somit | 因而、这样一来 | 【书面】 |
| mithin | 因此、可见 | 【书面·少用】 |
| deshalb/deswegen/darum/daher | 因此、所以（详见原因专栏） | 通用【常用】 |

| 例句 | 翻译 |
|------|------|
| Er hat verschlafen, **folglich** kam er zu spät. | 他睡过头了，因此迟到了。 |
| Es schneite stark, **infolgedessen** wurde der Flug gestrichen. | 雪下得很大，因此航班被取消了。 |
| Sie hat viel gelernt, **demnach** wird sie bestehen. | 她学了很多，由此可见她会通过的。 |
| Er ist krank, **dementsprechend** bleibt er zu Hause. | 他病了，因而（相应地）待在家里。 |

> 💡 互通链条：**sodass 从句 ↔ 主句 + 结果副词**：Er kam zu spät, **sodass** er den Zug verpasste. ↔ Er kam zu spät, **deshalb/infolgedessen** verpasste er den Zug.
> ⚠️ deshalb 家族已收入《原因从句》专栏；本专栏重点为"纯结果"副词 folglich 家族。

## 十、B1：结果名物化（Nominalisierung）【infolge 已学 08-04，其余补充】

### 1. infolge + Genitiv — 由于……的结果【书面】【已学】

| 从句 | 介词短语 |
|------|----------|
| Es wurde kalt, sodass ... | **infolge der Kälte** |
| Der Unfall passierte, sodass die Straße gesperrt wurde. | **Infolge des Unfalls** war die Straße gesperrt. |

### 2. zufolge + Dativ（后置介词）【书面】【补充】

> ⚠️ 注意：zufolge 的语义实为"**根据/按照**"（表依据、来源），与 infolge（由于……的结果）**不同**，但因常一起出现在结果/来源类练习中，特此并列辨析。

| 例句 | 翻译 |
|------|------|
| **Dem Bericht zufolge** ist die Lage stabil. | 根据该报告，局势稳定。 |
| Dem Plan zufolge beginnen wir nächste Woche. | 按照计划，我们下周开始。 |

> ⚠️ zufolge 常**后置**：名词 + zufolge（dem Bericht zufolge）；接 **Dativ**。
> 📌 辨析：**infolge + Gen.**（因……的结果）vs **zufolge + Dat. 后置**（根据……）。前者表结果，后者表依据。

### 3. 动词化结果表达【补充】

| 结构 | 例 | 翻译 |
|------|-----|------|
| **zur Folge haben, dass...** | Der Streik hat **zur Folge, dass** viele Flüge ausfallen. | 罢工导致许多航班取消。 |
| **dazu führen, dass...** | Das Verhalten führt **dazu, dass** alle wütend werden. | 这种行为导致大家都生气。 |
| **die Folge davon ist, dass...** | **Die Folge davon ist, dass** wir sparen müssen. | 其结果是我们必须省钱。 |
| **führen zu + Dat.** | Der Fehler führte **zu** einem großen Verlust. | 这个错误导致了巨大损失。 |

> 📌 三形变：führen → führte → hat geführt；folgen → folgte → ist gefolgt（本结构 zur Folge haben 用 haben）。

**转换三步法**（与原因专栏同款）：
```
1. 找从句核心动词 → 派生名词（kalt werden → die Kälte）
2. 根据从句类型 → 选对应介词（Konsekutiv: sodass → infolge）
3. 从句主语 → Genitiv；其余定语一并转换
```

### 4. 结果名词词族辨析（B1/B2）【补充】

| 名词 | 词性·复数 | 含义 | 侧重点 |
|------|-----------|------|--------|
| die **Folge** | die, -n | 结果、后果 | 直接结果，最常用 |
| das **Ergebnis** | das, -se | 结果、成果 | 计算/调查/考试的结果 |
| die **Konsequenz** | die, -en | 后果（常负面） | 需承担的行为后果 |
| die **Auswirkung** | die, -en | 影响、效应 | 对……产生的影响 |

| 例句 | 翻译 |
|------|------|
| Die **Folge** des Unfalls war ein langer Stau. | 事故的结果是长时间堵车。 |
| Das **Ergebnis** der Prüfung war gut. | 考试结果不错。 |
| Er muss die **Konsequenzen** tragen. | 他必须承担后果。 |
| Der Klimawandel hat **Auswirkungen** auf die ganze Welt. | 气候变化对全世界都有影响。 |

## 十一、B2：高级结果表达【补充】

### 1. sodass + Konjunktiv II — 结果未实现

当结果并未真正发生（主观判断/未完成）时，sodass 从句可用 KII：

| 例句 | 翻译 |
|------|------|
| Er sprach so leise, **sodass** man ihn kaum **verstehen könnte**. | 他说得那么轻，几乎听不见。（可能的结果，未实现） |

### 2. 结果从句的四种写法互转（写作能力）

| 结构 | 例句 |
|------|------|
| 从句 | Die Krise war so schwer, **dass** viele Firmen bankrottgingen. |
| 副词 | Die Krise war schwer; **infolgedessen** gingen viele Firmen bankrott. |
| 名物化 | **Infolge der schweren Krise** gingen viele Firmen bankrott. |
| 动词化 | Die schwere Krise hatte **zur Folge, dass** viele Firmen bankrottgingen. |

### 3. 语体梯度（口语 → 书面）

| 语体 | 表达 |
|------|------|
| 口语 | ...deshalb / also / so ein + N, dass... |
| 通用 | ...sodass... / so...dass |
| 书面 | ...solch-...dass / folglich / demnach... |
| 正式/公文 | ...infolgedessen / mithin... / infolge + Gen. |

## 十三、语体与使用频率标注（现代德语真实使用情况 · 重点必读）

### 第一梯队 ·【常用】—— 口语与书面都高频，必须主动掌握

| 表达 | 级别 | 说明 |
|------|------|------|
| sodass / so dass | B1 | 最常用结果连词 |
| so + Adj./Adv. + dass | B1 | 最常用程度+结果结构 |
| so ein/eine + N + dass | B1/B2 | 口语版 solch- |
| zu + Adj. + um...zu | A2 | 程度+结果（太……不能） |
| genug + um...zu | A2/B1 | 程度+结果（足够……可以） |
| also | B1 | 口语"所以" |
| deshalb / deswegen / darum / daher | B1 | 通用"因此"（归原因专栏） |

### 第二梯队 ·【书面】—— 正式写作/新闻常用，口语少用（识别 + 写作可用）

| 表达 | 级别 | 说明 |
|------|------|------|
| solch- + N + dass | B2 | 名词性程度+结果 |
| zu + Adj. + als dass + K II | B1/B2 | 异主语"太……不能" |
| folglich / demnach / infolgedessen / somit | B1 | 书面结果副词 |
| dementsprechend | B1 | 书面"相应地" |
| infolge + Gen | B1 | 名物化"因……的结果" |
| zufolge + Dat.（后置） | B1 | 实为"根据"（依据义，非结果） |
| zur Folge haben / dazu führen, dass / führen zu | B1 | 动词化"导致" |
| sodass + K II | B2 | 未实现的结果 |

### 第三梯队 ·【书面·少用】—— 口语几乎不用，仅需认识

| 表达 | 级别 | 说明 |
|------|------|------|
| derart / dermaßen / derartig + dass | B1 | 语气更强的"如此" |
| mithin | B1 | 很正式的"因此" |

### 第四梯队 ·【文学/陈旧】【近绝迹】【法律公文】

> 结果从句家族整体**偏实用**，无「文学/陈旧」「近绝迹」「法律公文」类必收录项；最书面者仅 mithin（很正式），但仍属可识别范围。此处无需刻意记忆冷门表达。

### 一句话总结

**口语日常只需：** sodass / so...dass / so ein...dass / zu...um zu / genug...um zu / also；
**书面写作再加：** solch-...dass、zu...als dass + KII、folglich 家族、infolge + Gen、zur Folge haben；
**其余（derart/dermaßen、mithin）：** 认识即可，主动输出一律用 so...dass。

## 十四、常见错误提醒（Fehlerquelle）

| 错误 | 正确 | 说明 |
|------|------|------|
| zu kalt, um schwimmen | um **zu** schwimmen | 不定式前的 zu 不能省 |
| genug alt | **alt genug** | 形容词在前、genug 在后 |
| zu kalt, dass man nicht schwimmen kann | als dass man schwimmen **könnte** | 异主语时用 als dass + KII |
| als dass er arbeiten **kann** | als dass er arbeiten **könnte** | als dass 从句必须 KII |
| ~~Sodass~~ ...（句首） | ...sodass...（句中） | sodass 不能置句首 |
| so kalt, dass wir blieben zu Hause | dass wir zu Hause blieben | dass 从句动词落尾 |
| Er ist müde, **um** zu schlafen | Er ist so müde, **dass** er schläft. | 客观结果用 sodass/dass，不用 um...zu |
| Er lernt, sodass er die Prüfung bestehen **will** | Er lernt, **um** die Prüfung zu bestehen. | 主观意图用目的从句 |
| zu kalt, dass...（缺 als） | zu kalt, **als dass**... | zu + Adj. 后接 als dass（异主语） |
| so Hunger（so 直接修饰名词） | **solchen** Hunger / **so einen** Hunger | so 修饰形容词，solch-/so ein 修饰名词 |

## 十五、记忆技巧

1. **sodass = 结果**（客观事实已发生）— 尾语序，不能开头
2. **so + Adj. + dass = 如此……以至于**（程度 + 结果）
3. **solch- / so ein + N + dass = 名词版"如此"**（so 修形容词，solch- 修名词）
4. **zu...um...zu = 太……不能**（同主语，双 zu 勿漏）
5. **zu...als dass + KII = 太……不能**（可异主语，虚拟语气）
6. **genug = 形容词在前**（alt genug）
7. **结果 vs 目的**：已发生 → sodass；未发生 → um...zu / damit
8. **folglich 家族 = 书面"因此"**；infolge + Gen. = 名物化"由于……的结果"
9. **infolge（结果）vs zufolge（根据）**：一个表结果，一个表依据
10. **因果链**：weil（原因）→ 主句 → sodass（结果），一条完整的因果链

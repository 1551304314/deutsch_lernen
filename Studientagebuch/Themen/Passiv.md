## 一、Passiv 概念：主动 vs 被动

**语态（Genus Verbi）**回答"主语是动作的发出者还是承受者"，与语气（Modus：直陈式/虚拟式/命令式）是两个不同范畴。

- **主动句（Aktiv）**：主语执行动作，突出"谁做"。
- **被动句（Passiv）**：主语承受动作，突出"动作本身与承受者"。

| | 例句 | 强调 |
|---|---|---|
| 主动 | Die Firma **baut** eine neue Brücke. | 谁在建 |
| 被动 | Eine neue Brücke **wird gebaut**. | 桥被建 |

**使用被动的三大场景**：
1. 施动者不重要：Das Zimmer wird täglich gereinigt. 房间每天被打扫。
2. 施动者未知：Mein Fahrrad wurde gestohlen. 我的自行车被偷了。
3. 施动者显而易见：Der Kaffee wird getrunken. 咖啡被喝了。

## 二、Vorgangspassiv（过程被动）构成【常用】— A2 核心公式

```
Vorgangspassiv = werden（表被动，随时态变位）+ Partizip II（固定句末，不变）
```

### werden 现在时变位全表

| 人称 | werden（现在时） | werden（过去时） |
|:--:|:--:|:--:|
| ich | **werde** | **wurde** |
| du | **wirst** | **wurdest** |
| er/sie/es | **wird** | **wurde** |
| wir | **werden** | **wurden** |
| ihr | **werdet** | **wurdet** |
| sie/Sie | **werden** | **wurden** |

### 三时态核心（A2 必考）

| 时态 | 主动 | 被动 |
|---|---|---|
| Präsens | repariert | **wird** repariert |
| Präteritum | reparierte | **wurde** repariert |
| Perfekt | hat repariert | ist repariert **worden** |

**例句**：
- Das Auto **wird** jeden Samstag **gewaschen**. → 这辆车每周六被洗。（现在时）
- Die Stadt **wurde** 1945 stark **zerstört**. → 这座城市 1945 年被严重摧毁。（过去时）
- Die Arbeit **ist** endlich **gemacht** **worden**! → 工作终于被做完了！（完成时）

> ⚠️ **最大易错点**：被动**完成时**用 `ist ... worden`，**绝不用 geworden**！`geworden` 是 werden 作"变成"义时的 PII；被动完成时把 werden 的 PII 去掉 ge-，写成 **worden**。
> 另一易错点：被动完成时助动词用 **sein**（不是 haben）。

## 三、主动 → 被动四步法【常用】

以 `Die Mutter kocht das Essen.`（妈妈做饭）为例：

| 步骤 | 操作 | 结果 |
|---|---|---|
| ① 宾语变主语 | das Essen（Akk）→ Nominativ | **Das Essen** |
| ② 主语走 von | die Mutter → **von + Dativ** | von der Mutter |
| ③ 谓语变被动 | kocht → **werden 变位 + PII** | wird gekocht |
| ④ 时态保留 | 原时态不变 | → |

**结果**：Das Essen wird von der Mutter gekocht.

**注意**：
- 施动者不重要时可省略 von 短语。
- 原句的 **man** 在被动中直接消失：Man spricht Deutsch. → Deutsch wird gesprochen.

## 四、von / durch / mit 三介词【常用】

| 介词 | 搭配 | 用法 | 例句 |
|---|---|---|---|
| **von** + Dativ | 人/机构/自然力 | 真正施动者 | Der Text wird **von Anna** geschrieben. |
| **durch** + Akk | 媒介/原因 | 通过… | Das Fenster wurde **durch den Wind** geöffnet. |
| **mit** + Dativ | 工具/材料 | 用什么 | Der Brief wird **mit dem Füller** geschrieben. |

> 口诀：**人是 von，工具 mit，媒介原因是 durch。**
> ⚠️ von 支配第三格（Dativ）：`von dem Mechaniker`，不是 ~~von den Mechaniker~~。

## 五、无人称被动（B1）【常用】

不及物动词无第四格宾语，用形式主语 **es** 占句首：
- Es wird hier viel **gearbeitet**. → 这里有很多工作在做。
- Es wird auf dem Fest viel **getanzt**. → 节日上有很多跳舞。

> ⚠️ **es 是占位符**：其他成分提到句首则 es 消失，动词保持第二位：
> Es wird hier viel getanzt. = **Hier** wird viel getanzt.
> ❌ 不能说 ~~Hier es wird viel getanzt.~~

## 六、情态动词 + 被动（B1）【常用】

构成：**情态动词 + Partizip II + werden**（三者都在句末，werden 在最末）。

| 情态动词 | 例句 |
|---|---|
| müssen | Das Formular muss ausgefüllt **werden**. |
| können | Das Problem kann gelöst **werden**. |
| dürfen | Hier darf nicht geraucht **werden**. |
| sollen | Der Text soll gelesen **werden**. |

---

## 七、被动在从句中的语序（B1）【常用】

从句中动词全部沉底：**Partizip II 沉最底，werden 在其前**。

| 从句类型 | 语序 |
|---|---|
| 无情态动词 | dass das Auto repariert **wird** |
| 有情态动词 | dass das Problem gelöst **werden kann** |

---

## 八、被动态中的介词宾语与第三格宾语（B1）【常用】

### 1. 介词宾语原样保留，动词变无人称被动
- Auf den Bus wird (von den Studenten) **gewartet**. → 公交车被（学生们）等。
- **Über das Problem** wird viel gesprochen. → 关于这个问题讨论很多。（介词短语提句首，es 消失）

### 2. 双宾动词被动只把"物"提为主语，"人"留守第三格
- Die Bücher werden **den Schülern** gegeben. → 书被发给学生们。
- Dem Patienten wird geholfen. → 病人得到帮助。（无人称被动，helfen 支配 Dativ）

## 九、Zustandspassiv（状态被动）【常用】— B1 高分分水岭

| | 过程被动（Vorgangspassiv） | 状态被动（Zustandspassiv） |
|---|---|---|
| 构成 | **werden** + PII | **sein** + PII |
| 含义 | 动作正在/曾被**执行**（动态过程） | 动作完成后的**状态/结果**（静态） |
| 问法 | Was passiert? 发生了什么？ | Wie ist der Zustand? 状态如何？ |

**对比例句**：
- Die Tür **wird geöffnet**. 门正在被打开。（过程）
- Die Tür **ist geöffnet**. 门开着。（状态）

**状态被动时态**（只有 sein 变，分词不变）：

| 时态 | 例句 |
|---|---|
| Präsens | Die Tür **ist** geöffnet. |
| Präteritum | Die Tür **war** geöffnet. |
| Perfekt | Die Tür **ist** geöffnet **gewesen**.（少见） |
| Futur I | Die Tür **wird** geöffnet **sein**. |

> ⚠️ 状态被动完成时用 **gewesen**，过程被动完成时用 **worden**，勿混。
> **判断测试法**：能改写为 "Das Ergebnis ist, dass…"（结果是…）→ 用状态被动。

## 十、被动完整时态速查表

| 时态 | 过程被动（werden） | 状态被动（sein） |
|---|---|---|
| Präsens | wird repariert | ist repariert |
| Präteritum | wurde repariert | war repariert |
| Perfekt | ist repariert **worden** | ist repariert **gewesen** |
| Plusquamperfekt | war repariert **worden** | war repariert **gewesen** |
| Futur I | wird repariert **werden** | wird repariert **sein** |
| 情态动词+被动 | muss repariert **werden** | muss repariert **sein** |

## 十一、bekommen-Passiv（三格宾语被动 / 受惠者被动）B2【口语】

**德语术语**：bekommen-Passiv（Rezipientenpassiv 受惠者被动 / Dativpassiv 三格被动）。

### 为什么需要它
普通被动态只能把 **Akk（第四格）宾语**提为主语。当句子重心是**受益的"人"**（第三格宾语）时，用 `bekommen` 把这个人提为主语。

| 语态 | 例句 |
|---|---|
| 主动 | Die Firma **liefert** mir das Paket. 公司给我送包裹。 |
| 普通被动 | **Mir** wird das Paket geliefert. 包裹被送给我。（人留守第三格） |
| **bekommen-Passiv** | **Ich bekomme** das Paket **geliefert**. 我收到包裹。 |

### 结构：`bekommen（随时态变位）+ PII（句末不变）`

| 时态 | 例句 |
|---|---|
| Präsens | Ich **bekomme** geliefert. |
| Präteritum | Ich **bekam** geliefert. |
| Perfekt | Ich **habe** geliefert **bekommen**. |
| Plusquamperfekt | Ich **hatte** geliefert **bekommen**. |
| 情态动词 | Ich **muss** geliefert **bekommen**. |

### 适用范围（⚠️ 不是万能）
- **动词类型**：只用于带 Dativ 宾语的动词，主要是"给出/传递"类——geben, schenken, bringen, schicken, senden, liefern, zahlen, überreichen, anbieten, versprechen, erzählen, sagen, zeigen, mitteilen。
  - ✅ `Ich bekomme die Wahrheit gesagt.` 我被告知真相。
  - ❌ `*Das Buch bekommt gekauft.` 错误——kaufen 无 Dativ 宾语，只能用 `Das Buch wird gekauft.`
- **语体**：口语/非正式为主。正式书面德语倾向 `Mir wird … + PII`。
- **无 Akk 宾语时**（如 helfen）可说 `Ich bekomme geholfen.`，更口语，书面受限。

**其他助动词**：口语 `kriegen`；非常正式 `erhalten`（少用）。

> 记忆技巧：bekommen 按字面"得到"理解——"我得到被…的动作"，中文译成"我收到…/我被…了"。

## 十二、Passiversatzformen（被动替代形式）B2 ⭐ 核心缺口

| 形式 | 结构 | 对应含义 | 语体 |
|---|---|---|---|
| man 结构 | man + 主动 | = wird + PII | 口语/泛指 |
| sein + zu | sein + zu + Inf. | = **muss 或 kann** + PII | 书面/官方 |
| sich lassen | sich + lassen + Inf. | = **nur kann** + PII | 口语/书面 |
| 形容词后缀 | -bar / 少数 -lich | = kann + PII | 书面 |

### 1. man + 主动【常用·口语】（A2 已见，正式归入替代体系）
`Man spricht hier Deutsch.` = `Hier wird Deutsch gesprochen.` 这里说德语。

### 2. sein + zu + Infinitiv【书面·官方】（"必须"还是"可能"三步判断法）
**构成**：`主语 + ist/sind + zu + Infinitiv`

1. 有程度副词 **gut / leicht / schwer / kaum / nur / ohne weiteres** → 表**可能**（= können）
2. 有**时间/命令/规定**语境（sofort, bis …, Regel, Vorschrift）→ 表**必须**（= müssen）
3. 无提示词的中性句（主语是 Aufgabe/Regel/Plan）→ 通常读作**必须**

| 判定 | 例句 | 等价改写 |
|---|---|---|
| 可能 | Der Text **ist leicht zu verstehen**. | kann leicht verstanden werden |
| 必须 | Die Aufgabe **ist bis morgen zu erledigen**. | muss erledigt werden |
| 不可能（否定） | Das **ist nicht zu ändern**. | kann nicht geändert werden |
| 不可能（否定+程度） | Das **ist kaum zu vermeiden**. | kann kaum vermieden werden |

**限制**：只用于**可被动化的及物动词**；`*Der Hund ist zu bellen` 不成立。

### 3. sich + lassen + Infinitiv【常用】（只表"可能"，绝不表"必须"）
- `Das Problem **lässt sich lösen**.` = Das Problem kann gelöst werden.
- `Die Tür **lässt sich nicht öffnen**.` 门打不开。
- `Der Text **lässt sich leicht übersetzen**.`

**与 sein+zu 的本质区别**：sein+zu 兼表必须/可能；**sich lassen 只能表"可能"**，muss 含义永远无法用它表达。

### 4. 形容词后缀【书面】（边界讲死）
- **-bar**（动词词干 + -bar）→ "可以被…的"，规则最活：waschbar, essbar, trinkbar, lesbar, lösbar, machbar, sichtbar, reparierbar, übersetzbar
  - ⚠️ **例外**（非被动义，单独背）：dankbar 感恩的、fruchtbar 肥沃的、furchtbar 可怕的
- **-lich**【书面·少用】→ 被动义是**少数固定词，不可类推**：verständlich, begreiflich, unvermeidlich, erträglich
  - ⚠️ 大量 -lich 与被动无关：freundlich, täglich, körperlich

**等价链条**（同一意思四种说法）：
`Das Problem ist lösbar.` ≈ `Das Problem lässt sich lösen.` ≈ `Das Problem kann gelöst werden.` ≈ `Das Problem ist zu lösen.`

## 十三、被动 + 第二虚拟式（修正版）B1/B2

**非现实被动只有两层时态**，记住"主动二虚 → 被动二虚"的对应：

| 层面 | 主动二虚 | 过程被动二虚 | 状态被动二虚 |
|---|---|---|---|
| 现在层（非现实现在/将来） | würde + Inf. | **würde + PII + werden** | **würde + PII + sein** |
| 过去层（非现实过去） | hätte/wäre + PII | **wäre + PII + worden** | **wäre + PII + gewesen** |
| 情态动词·现在层 | könnte/müsste + Inf. | könnte/müsste + PII + werden | könnte/müsste + PII + sein |
| 情态动词·过去层 | hätte + Inf. + können | **hätte + PII + werden + können/müssen** | 罕见 |

**例句**：
- 现在层：`Wenn mehr Geld da wäre, würde das Haus schneller gebaut werden.` 若钱更多，房子会建得更快。
- 过去层：`Die Tür wäre längst geöffnet worden.` 门本应早就被打开。
- 过去层状态：`Das Zimmer wäre aufgeräumt gewesen.` 房间本该是收拾好的。
- 情态现在层：`Es müsste mehr für die Umwelt getan werden.` 应更多地为环境做事。
- 情态过去层：`Es hätte früher gemacht werden können.` 这本可以更早完成。

> ⚠️ **易混澄清**：被动二虚过去层是 `wäre + PII + worden`，**不是** `würde + PII + worden sein`——后者是"二虚将来二时被动"（Konjunktiv II Futur II Passiv），DaF A1–B2 不考，别用。
> 记忆：被动二虚过去层 = 把主动过去层（hätte/wäre + PII）的 PII 换成被动态：worden / gewesen。

## 十四、zu-Infinitiv 被动 + Plusquamperfekt/Futur 实操（B1 收尾）

### 1. zu-Infinitiv 被动
结构：`… zu + PII + werden / sein`，常配 scheinen, hoffen, wünschen, bitten 等：
- `Das Haus scheint renoviert zu werden.` 房子似乎正在被翻修。
- `Es ist wichtig, rechtzeitig informiert zu werden.` 及时获知信息很重要。
- `Er hofft, bald eingeladen zu werden.` 他希望能很快被邀请。

### 2. Plusquamperfekt / Futur 被动实操
- **Plusquamperfekt Passiv**（过去之过去，常配 nachdem）：
  - `Nachdem das Problem gelöst worden war, gab es keine Fragen mehr.` 问题解决后，再无疑问。
- **Futur I Passiv**：
  - `Die Aufgabe wird morgen gelöst werden.` 任务明天将被解决。
- **对比 Futur II Passiv**（对应二虚将来二时的直陈式形态）：
  - `Die Aufgabe wird morgen gelöst worden sein.` 明天之时任务将已经完成。

## 十五、被动化的限制（哪些动词不能进被动）B1 常考 ⭐

被动不是万能的。三条"禁区"：

### 禁区 1：不及物动词（无 Akk 宾语）
- 只能进**无人称被动**，且限于表"活动/过程"的动词：✅ `Es wurde die ganze Nacht getanzt.` ✅ `Hier wird nicht geraucht.`
- **存在/状态**类不及物动词连无人称被动都不行（sein, bleiben, liegen, stehen, sitzen, existieren）：❌ `*Es wird gelegen.`
- 带 Dativ 的不及物动词 → 无人称被动（`Dem Kind wird geholfen.`）或 bekommen-Passiv。

### 禁区 2：反身动词（详见第十七节）
❌ `*Es wird sich gefreut.` 错误。

### 禁区 3：静态/领属/感知类动词——绝对不能被动化
这类动词表"状态"不表"动作"：

| 动词 | 错误句 | 正确表达 |
|---|---|---|
| haben | ❌ `*Der Brief wird von mir gehabt.` | ✅ Ich habe den Brief. |
| wissen / kennen | ❌ `*Es wird gewusst.` | ✅ Das ist bekannt. |
| bekommen | ❌ 不能被动 | ✅ bekommen-Passiv 本身 |
| enthalten | ❌ 不能被动 | ✅ Die Flasche enthält Wasser. |
| kosten | ❌ `*10 Euro werden gekostet.` | ✅ Das Buch kostet 10 Euro. |
| gleichen / ähneln | ❌ 不能被动 | ✅ Sie gleicht ihrer Mutter. |

> 判断口诀：先问"能被…吗？"——拥有、知道、花费、相似这类**状态**动词答不出来，就不能被动；表**动作/过程**的才进得了被动。

## 十六、Gerundiv（zu-分词作定语）B1/B2 ⭐【书面】

**定义**：`zu + PII` 作名词定语，表"**需要/有待被…的**"（被动 + 必要性）。

**构成**：`zu + PII + 形容词词尾（随名词变格）`

| 例句 | 等价句式 |
|---|---|
| das **zu lösende** Problem 待解决的问题 | = Das Problem ist zu lösen. |
| der **zu reparierende** Motor 待修的发动机 | = Der Motor ist zu reparieren. |
| die **zu erledigende** Aufgabe 待完成的任务 | = Die Aufgabe ist zu erledigen. |

**变格示例**：定冠词 `das zu lösende Problem` / `mit dem zu lösenden Problem`；无冠词 `zu lösende Probleme`（复）。

**三个分词对比**（reparieren）：

| 形式 | 语态·时态 | 例句 |
|---|---|---|
| Partizip I：der reparier**ende** Mann | 主动·进行 | 正在修理的男人 |
| Partizip II：der reparier**te** Motor | 被动·已完 | 已修好的马达 |
| **Gerundiv**：der **zu** reparierende Motor | 被动·需然 | 待修的马达 |

**要点**：
- 只用于**可被动化的及物动词**。
- 否定：`der nicht zu reparierende Motor` = 无法修理的马达（= nicht reparierbar）。
- 可带扩展成分：`die noch zu erledigenden Aufgaben` 尚未完成的任务。
- 记忆：直译"to be done 的"，对照英语 `the book to be read`。

## 十七、lassen 使役结构 vs sich lassen（B1/B2）⭐

### 1. lassen 使役结构（lassen + Akk + Infinitiv）【常用】
**含义**：主语"安排/让/允许"某事发生，但**不亲自做**。

**结构**：`lassen（变位）+ 宾语 + Infinitiv（句末）`

| 例句 | 含义 |
|---|---|
| Ich **lasse** das Auto **reparieren**. | 我让人修车。 |
| Ich **lasse mir** die Haare **schneiden**. | 我去理发。 |
| Er **lässt** seinen Sohn die Tür **öffnen**. | 他让儿子开门。 |
| Ich **lasse mich** impfen. | 我让人给我打疫苗。 |

**三个语义**：① 使役（Er lässt das Haus bauen.）② 允许（Die Eltern lassen das Kind fernsehen.）③ 保持/任凭口语（Lass das! / Lass mich in Ruhe!）

> ⚠️ **Perfekt 双不定式**（句末保留 **lassen** 不定式，绝不写 gelassen）：
> ✅ `Ich habe das Auto reparieren lassen.` ✅ `Er hat sich impfen lassen.` ✅ `Er muss das Auto reparieren lassen.`

### 2. 与 sich lassen 一字之差，务必分清（B1/B2 区分考点）

| 句子 | 结构 | 语义 |
|---|---|---|
| Das Problem **lässt sich** lösen. | 被动替代 | 问题**可以**解决。 |
| Ich **lasse** das Problem lösen. | 使役 | **我让人**解决问题。 |

## 十八、反身动词无被动（B1）⭐

**铁律**：反身动词的**反身用法**绝对不能被动化。
❌ `*Es wird sich gefreut.` ❌ `*Es wird sich getroffen.`

**关键区分**（考试判断标准）——看动词有无"非反身的及物用法"：

| 动词 | 反身用法（无被动） | 及物用法（可被动） |
|---|---|---|
| waschen | Er wäscht sich. → ❌无被动 | ✅ Das Kind wird gewaschen. |
| treffen | Sie treffen sich. → ❌无被动 | ✅ Das Ziel wird getroffen. |
| anziehen | Ich ziehe mich an. → ❌无被动 | ✅ Die Hose wird angezogen. |

**纯反身动词**（绝对无被动）：sich freuen, sich befinden, sich bedanken, sich erholen, sich beeilen, sich schämen, sich erkälten, sich weigern, sich bemühen...

**被动义的替代表达**：
- 用 man：`Man freut sich über das Geschenk.`
- 用形容词：`Das ist erfreulich.` 这是令人高兴的。
- 用名词：`Die Freude über das Geschenk.`

## 二十二、常见错误提醒（Fehlerquelle）

| ❌ 错误 | ✅ 正确 | 原因 |
|------|------|------|
| Das Auto ist repariert **geworden**. | …ist repariert **worden**. | 被动完成时用 worden，"变成"才用 geworden |
| …von **den** Mechaniker | …von **dem** Mechaniker | von 支配第三格 |
| …**hat** repariert worden | …**ist** repariert worden | 被动完成时用 sein 系 |
| Das Auto wird repariert **worden**（Präsens） | Das Auto wird repariert | 现在时只有一个 werden |
| Das Auto wurde repariert **worden**（Präteritum） | Das Auto wurde repariert | 过去时也只有一个 werden |
| 状态被动完成时用 worden | …ist geöffnet **gewesen** | 状态被动用 gewesen，过程被动用 worden |
| Hier **es** wird viel getanzt. | **Hier** wird viel getanzt. | es 是占位符，他人提句首即消失 |
| `*Das Buch bekommt gekauft.` | Das Buch wird gekauft. | kaufen 无 Dativ 宾语，不能用 bekommen-Passiv |
| `*Es wird sich gefreut.` | Man freut sich … | 反身动词无被动 |
| `*10 Euro werden gekostet.` | Das Buch kostet 10 Euro. | 静态动词不能被动化 |
| 被动二虚过去层 `würde + PII + worden sein` | `wäre + PII + worden` | 那是二虚将来二时被动，不考 |
| lassen 完成时写 gelassen | `Ich habe … reparieren lassen.` | Perfekt 双不定式保留 lassen |

## 二十三、记忆技巧

1. **被动公式 = werden + PII**：werden 变时态，分词守句尾。
2. **完成时砍 ge-**：geworden → **worden**（被动），状态被动用 **gewesen**。
3. **四步法**：宾语提主语 → 主语走 von → 谓语变被动 → 时态不变。
4. **人是 von，工具 mit，媒介原因是 durch**。
5. **es 是临时工**：有人占位就下岗。
6. **情态+被动**：三个动词沉句尾，werden 殿后。
7. **状态 = 定格画面**（sein + PII），**过程 = 进行动作**（werden + PII）。
8. **sein + zu 判断**：程度副词→可能；时间命令→必须。
9. **sich lassen 只表"可能"**，绝不表"必须"。
10. **被动禁区**：不及物（无 Akk）、反身、静态动词（haben/wissen/kosten…）。
11. **bekommen-Passiv = "我收到被…的动作"**（口语，仅带 Dativ 的传递类动词）。
12. **Gerundiv = "to be done"**：zu + PII + 形容词词尾。

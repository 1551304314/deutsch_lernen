## 详细内容

### 一、强变化动词推送（按 Ablaut 分组）

**e → a → e 组**

#### 1. lesen 读（朗读/阅读）
- **三形变**：lesen → las → **gelesen**
- 变位提示：现在时单数变音（du liest, er liest）
- 例句：
  - Der Text wird von Anna **gelesen**. → 这篇课文被安娜读。
  - Ich lese jeden Tag die Zeitung. → 我每天读报纸。

#### 2. sehen 看（看见）
- **三形变**：sehen → sah → **gesehen**
- 变位提示：现在时单数变音（du siehst, er sieht）
- 例句：
  - Das Denkmal wird von vielen Touristen **gesehen**. → 这座纪念碑被很多游客看到。
  - Sie sieht aus, als hätte sie nicht geschlafen. → 她看起来好像没睡过觉。

#### 3. geben 给
- **三形变**：geben → gab → **gegeben**
- 用法提示：双宾动词（Dat + Akk），被动中"物"提主语、"人"留守第三格
- 例句：
  - Die Bücher werden den Schülern **gegeben**. → 书被发给学生们。

**ei → ie → ie 组**

#### 4. schreiben 写
- **三形变**：schreiben → schrieb → **geschrieben**
- 例句：
  - Der Brief wird von Maria **geschrieben**. → 这封信被玛丽亚写。
  - Der Brief ist **geschrieben**. → 信写好了。（状态被动）

#### 5. bleiben 留/停留
- **三形变**：bleiben → blieb → **geblieben**
- 用法提示：不及物动词，只接 sein 助动词
- 例句：
  - Wenn das Wetter schön wäre, würden wir zu Hause **bleiben**? → 如果天气好，我们会留在家里吗？

## 详细内容

## 专题一：被动语态（das Passiv）

### 一、核心概念：主动 vs 被动

- **主动句**：主语执行动作，突出"谁做"。
- **被动句**：主语承受动作，突出"动作本身与承受者"。

| | 例句 | 强调 |
|---|---|---|
| 主动 | Die Firma **baut** eine neue Brücke. | 谁在建 |
| 被动 | Eine neue Brücke **wird gebaut**. | 桥被建 |

**使用被动三大场景**：
1. 施动者不重要：Das Zimmer wird täglich gereinigt.
2. 施动者未知：Mein Fahrrad wurde gestohlen.
3. 施动者显而易见：Der Kaffee wird getrunken.

### 二、构成规则：werden + Partizip II（A2 核心公式）

被动 = 助动词 **werden**（表被动，随时态变位）+ 动词**过去分词**（固定句末，不变）。

| 时态 | 主动 | 被动 |
|---|---|---|
| Präsens | repariert | **wird** repariert |
| Präteritum | reparierte | **wurde** repariert |
| Perfekt | hat repariert | ist repariert **worden** |
| Plusquamperfekt | hatte repariert | war repariert **worden** |
| Futur I | wird reparieren | wird repariert **werden** |

> ⚠️ **最大易错点**：被动**完成时**用 `ist ... worden`，**绝不用 geworden**！

### 三、主动 → 被动四步法

以 `Die Mutter kocht das Essen.` 为例：

| 步骤 | 操作 | 结果 |
|---|---|---|
| ① 宾语变主语 | das Essen（Akk）→ Nominativ | **Das Essen** |
| ② 主语走 von | die Mutter → **von + Dativ** | von der Mutter |
| ③ 谓语变被动 | kocht → **werden 变位 + PII** | wird gekocht |
| ④ 时态保留 | 原时态不变 | → |

**结果**：Das Essen wird von der Mutter gekocht.
**注意**：施动者不重要可省略 von 短语；原句的 man 在被动中直接消失（Man spricht Deutsch. → Deutsch wird gesprochen.）

### 四、von / durch / mit 三介词

| 介词 | 搭配 | 用法 | 例句 |
|---|---|---|---|
| **von** + Dativ | 人/机构/自然力 | 真正施动者 | Der Text wird **von Anna** geschrieben. |
| **durch** + Akk | 媒介/原因 | 通过… | Das Fenster wurde **durch den Wind** geöffnet. |
| **mit** + Dativ | 工具/材料 | 用什么 | Der Brief wird **mit dem Füller** geschrieben. |

口诀：**人是 von，工具 mit，媒介原因是 durch。**

### 五、无人称被动（B1）

不及物动词无第四格宾语，用形式主语 **es** 占句首：
- Es wird hier viel **gearbeitet**.
- Es wird auf dem Fest viel **getanzt**.

> ⚠️ **es 是占位符**：其他成分提句首则 es 消失，动词保持第二位：
> Es wird hier viel getanzt. = **Hier** wird viel getanzt.

### 六、情态动词 + 被动（B1）

构成：**情态动词 + Partizip II + werden**（都在句末）。

| 情态动词 | 例句 |
|---|---|
| müssen | Das Formular muss ausgefüllt **werden**. |
| können | Das Problem kann gelöst **werden**. |
| dürfen | Hier darf nicht geraucht **werden**. |
| sollen | Der Text soll gelesen **werden**. |

### 七、状态被动 Zustandspassiv：sein + Partizip II（B1 高分分水岭）

| | 过程被动（Vorgangspassiv） | 状态被动（Zustandspassiv） |
|---|---|---|
| 构成 | **werden** + PII | **sein** + PII |
| 含义 | 动作正在/曾被**执行**（动态过程） | 动作完成后的**状态/结果**（静态） |
| 问法 | Was passiert? | Wie ist der Zustand? |

**对比例句**：
- Die Tür **wird geöffnet**. 门正在被打开。（过程）
- Die Tür **ist geöffnet**. 门开着。（状态）

**状态被动时态**（只有 sein 变，分词不变）：
| 时态 | 例句 |
|---|---|
| Präsens | Die Tür **ist** geöffnet. |
| Präteritum | Die Tür **war** geöffnet. |
| Futur I | Die Tür **wird** geöffnet **sein**. |

> ⚠️ 状态被动完成时用 **gewesen**，别和过程被动的 **worden** 混！

**判断测试法**：能改写为 "Das Ergebnis ist, dass…"（结果是…）→ 用状态被动。

### 八、被动在从句中的语序（B1）

从句中动词全部沉底：**Partizip II 沉最底，werden 在其前**。

| 从句类型 | 语序 |
|---|---|
| 无情态动词 | dass das Auto repariert **wird** |
| 有情态动词 | dass das Problem gelöst **werden kann** |

### 九、被动态中的介词宾语（B1）

介词宾语原样保留，动词变无人称被动：
- Auf den Bus wird (von den Studenten) **gewartet**.
- **Über das Problem** wird viel gesprochen.（介词短语提句首，es 消失）

### 十、被动态中的第三格宾语（B1 进阶）

双宾动词被动只把**物**提为主语，"人"留守第三格：
- Die Bücher werden **den Schülern** gegeben.
- Dem Patienten wird geholfen.（无人称被动）

### 十一、必须用被动的场景（写作加分点）

1. 官方公告/规定：Hier wird nicht geraucht.
2. 新闻/报道：Der Präsident wurde gestern gewählt.
3. 学术/说明文：Die Daten werden analysiert.
4. 无需/无法指出施动者：Das Fenster wurde eingeworfen.

### 十二、被动完整时态速查表

| 时态 | 过程被动（werden） | 状态被动（sein） |
|---|---|---|
| Präsens | wird repariert | ist repariert |
| Präteritum | wurde repariert | war repariert |
| Perfekt | ist repariert **worden** | ist repariert **gewesen** |
| Plusquamperfekt | war repariert **worden** | war repariert **gewesen** |
| Futur I | wird repariert **werden** | wird repariert **sein** |
| 情态动词+被动 | muss repariert **werden** | muss repariert **sein** |

## 专题二：第二虚拟式（Konjunktiv II）

### 一、两个虚拟式的整体框架

| | Konjunktiv I（一虚） | Konjunktiv II（二虚） |
|---|---|---|
| 功能 | 间接引语（转述） | **非现实**（假设/愿望/礼貌） |
| 例句 | Er sagt, er komme morgen. | Wäre ich reich! |
| 学习阶段 | B2 | **B1（本次重点）** |

> 口诀：一虚是"别人的话"，二虚是"假的、想的事"。

### 二、核心意义：非现实（Irrealität）

| 现实 | 二虚 |
|---|---|
| Ich habe keine Zeit. | **Hätte** ich Zeit!（现实：没时间） |
| Es regnet. | Wenn es nicht regnete! |
| Ich fliege nach Berlin. | Ich würde nach Berlin fliegen.（现实：没飞） |

### 三、构成三大类

**① 强变化动词**：Präteritum 词干 + 变音（a/o/u→ä/ö/ü）+ 词尾

| 不定式 | Präteritum | Konjunktiv II |
|---|---|---|
| geben | gab | **gäbe** |
| kommen | kam | **käme** |
| nehmen | nahm | **nähme** |
| tragen | trug | **trüge** |
| finden | fand | **fände** |
| wissen | wusste | **wüsste** |

> 规律：过去时词干 a→ä、o→ö、u→ü + 虚拟词尾（e, est, e, en, et, en）；词干无 a/o/u 时（blieb, schrieb）与过去时同形。

**② 弱变化动词**：二虚 = 过去时形式（machte），口语中改用 würde + Infinitiv 区分。

**③ 三大"元老"（必背）**：

| 不定式 | 二虚 | 例句 |
|---|---|---|
| sein | **wäre** | Ich wäre gern in Berlin. |
| haben | **hätte** | Hättest du einen Moment Zeit? |
| werden | **würde** | Ich würde das nicht tun. |

**④ würde + Infinitiv（万能替代）**：弱动词/难记形式 → würde machen。
- 口语/日常：würde + Infinitiv 主力
- 书面/正式：强动词直接虚拟式（gäbe, käme）更优雅
- **例外**：wäre/hätte/würde 必须直接用，不说 würde sein / würde haben！

### 四、五大用法

**用法 1：非现实愿望**
- **Wenn** ich mehr Zeit **hätte**!
- **Hätte** ich mehr Zeit!（倒装）
- Wenn ich im Lotto gewonnen hätte!

**用法 2：非现实条件句**（核心）
- **Wenn** das Wetter gut **wäre**, **würden** wir wandern gehen.（现实：天气不好）
- **Wenn** ich du **wäre**, **würde** ich mehr üben.
- **Wenn** es nicht so teuer wäre, **kaufte** ich das Auto.（书面直接二虚）

**用法 3：礼貌请求**（日常最高频）
| 直白 | 礼貌 |
|---|---|
| Helfen Sie mir! | **Könnten** Sie mir bitte helfen? |
| Komm her! | **Könntest** du bitte herkommen? |
| Gib mir das Buch. | **Würdest** du mir bitte das Buch geben? |
| Das ist nicht richtig. | Das **wäre** nicht richtig. |

> 德语礼貌核心：Könnten / Würden + 请求 = 万能礼貌句。

**用法 4：非现实比较 als ob / als wenn / als**
- Er tut so, **als ob** er nichts **wüsste**.
- Sie sieht aus, **als** hätte sie nicht geschlafen.
- Er redet, **als wenn** er der Chef **wäre**.

**用法 5：建议 / 委婉评价**
- Man **könnte** das Problem anders lösen.
- Ich **würde sagen**, dass es funktioniert.
- Du **könntest** früher kommen.

### 五、时态：现在/将来 vs 过去

| 层面 | 构成 | 例句 |
|---|---|---|
| 现在/将来 | 二虚本身 | Ich wäre jetzt gern am Meer. |
| 过去（本该发生却未发生） | hätte/wäre + PII | Ich wäre gestern gekommen. |

- Hätte ich das gewusst!
- Ohne deine Hilfe wäre ich gescheitert.
- Ich hätte es machen können.（B2）

### 六、情态动词的二虚（B1 最高频）

| 情态动词 | 二虚 | 核心含义 | 例句 |
|---|---|---|---|
| können | **könnte** | 可能/委婉能力 | Könnten Sie mir bitte helfen? |
| müssen | **müsste** | 本该/想必 | Ich müsste jetzt gehen. |
| sollen | **sollte** | 建议/应当 | Du solltest mehr schlafen. |
| dürfen | **dürfte** | 应该（推测） | Das dürfte stimmen. |
| wollen | wollte | 想要（带未成意味） | Ich wollte dir helfen, aber… |
| mögen | **möchte** | 想要（最常用） | Ich möchte einen Kaffee. |

> 记忆：情态动词二虚 = 原意 + 客气/推测。

### 七、点餐三兄弟

| 表达 | 语气 | 例句 |
|---|---|---|
| Ich möchte… | 直接 | Ich möchte einen Kaffee. |
| Ich hätte gern… | 最客气 | Ich hätte gern ein Wasser. |
| Ich würde gern… | 委婉意图 | Ich würde gern zahlen. |

### 八、语气词 nur / doch / bloß 强化愿望

- Wenn ich **nur** mehr Zeit hätte!
- Hätte ich das **doch** gewusst!
- Wenn es **bloß** nicht regnete!

### 九、无连词条件句（倒装）

- **Wäre** das Wetter schön, gingen wir.（省略 wenn，动词提句首）

### 十、Es wäre + Adj., wenn…：建议句型

- **Es wäre besser**, wenn du früher kämest.
- **Es wäre schön**, wenn ihr uns besuchen könntet.

### 十一、B2 预告：过去层面情态动词二虚

| 结构 | 含义 | 例句 |
|---|---|---|
| hätte … können | 本可以 | Ich hätte früher kommen können. |
| hätte … sollen | 本不该/本该 | Das hätte ich nicht sagen sollen. |
| hätte … müssen | 本应该 | Du hättest deine Hausaufgaben machen müssen. |
| hätte … dürfen | 本不该被允许 | Das hätte nicht passieren dürfen. |

> 规律：情态动词沉最末，hätte 在主语后。

### 十二、口语高频二虚短语

Ich hätte gern… / Ich würde sagen… / Das wäre super! / Das würde ich nicht sagen. / Es könnte sein, dass… / Man könnte meinen… / Ich müsste mal… / Du könntest vielleicht… / Es wäre besser, wenn… / Wenn ich du wäre…

## 复习要点
- [ ] 主动→被动四步法即时转换（写作/口语实操）
- [ ] 状态被动 vs 过程被动快速判断（定格画面 sein / 进行动作 werden）
- [ ] 被动完成时 worden（非 geworden）；状态被动完成时 gewesen
- [ ] 被动从句语序：分词沉底 → werden → 情态动词
- [ ] 三剑客 wäre/hätte/würde 与情态动词二虚 könnte/müsste/dürfte/sollte/möchte
- [ ] 过去层面二虚：hätte/wäre + PII（本可以/本应）
- [ ] 礼貌请求万能公式：Könnten/Würden Sie bitte…
- [ ] 强动词虚拟式构成：过去时词干 + 变音
